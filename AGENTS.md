# Repository instructions

## Branch and push policy

- Work directly on the `main` branch unless the user explicitly instructs otherwise.
- After completing a requested implementation and validating it successfully, commit the changes and push them to `origin/main`.
- Do not leave completed changes only in the local working tree.
- This project uses GitHub Pages for verification, so pushing completed work to `main` is required for the user to confirm the result.
- If commit or push fails, do not claim completion. Report the failure and the exact reason.
- If the user explicitly says not to commit or not to push for a specific task, follow that instruction for that task.

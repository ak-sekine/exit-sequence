# 移動・描画仕様

3D表示と操作を確認するサンプル。敵、アイテム、クリア判定はない。

## マップと境界

src/dungeon.tsのDUNGEON_MAPは5行×5列。#は床、半角スペースは通行不可。

以下は末尾の半角スペースを省略して表示している。内部配列では各行を5列にそろえる。

```text
  #
#####
  #
  #
  #
```

左上が原点、Xは右、Yは下。初期位置は(2,4)、北向き。北へ3マスでT字路(2,1)に到達する。部屋は(2,0)の1マスだけで、北・東・西は壁。facingは北0・東1・南2・西3。

DOORSは床セルとは別の境界情報で、from=(2,1)、to=(2,0)。doorBetweenは両方向から境界を判定する。扉の開閉状態、タイマー、アニメーションは持たない。別マップには扉配列を明示的に渡せる。

上は1マス前進、左／右／下は座標を変えず90°左／90°右／180°回転。通常のmoveは床以外、マップ外、扉境界への前進を阻止する。AはpassDoorで正面の隣接扉を判定し、位置を直接1マス更新する。向きは維持する。開ける・通過・閉める処理は1回の操作で完了し、常に閉じた扉として描画する。正面に扉がなければAは状態もログも変更しない。Bは3D／2Dの2状態を切り替える。

## 描画

src/renderer.tsは閉じた境界を越えずに現在位置から到達できる床領域を抽出し、その壁境界と扉境界を求め、プレイヤーの座標・向きからカメラ座標へ変換する。壁面の平面で空間を分割するBSPにより、カメラから遠い側から手前へ描く。近クリップ面で切り取り、x/z、y/zで透視投影する。壁面をダンジョン背景色で塗り、緑色の輪郭線を描くことで奥の線を遮蔽する。正面壁、左右壁、閉じた扉の裏側は見えず、床同士の開口部には壁面を置かないため、実際に見える左右通路は表示される。特定のT字路に依存しない共通処理。

扉は壁面に長方形の枠、内部の横線、取っ手を描く。境界は一度だけ描画し、どちらの側からも同じ閉じた扉が見える。Aの移動直後にmain.tsが移動先のSVGを更新する。外部3Dライブラリは使用しない。

main.tsは入力、画面更新、言語メニュー、ログ追加を担当する。描画座標は移動判定に使わない。

## ログ

初期「通路にいる。」、成功「前進した。」、左「左を向いた。」、右「右を向いた。」、下「後ろを向いた。」、不可「これ以上進めない。」。前進不可でもログを追加する。

扉通過時だけ「扉を開けて部屋に入った。」「扉を開けて通路に戻った。」を追加する。英語はそれぞれ「Opened the door and entered the room.」「Opened the door and returned to the corridor.」。言語変更で既存ログも再翻訳する。

## 検証

npm testで初期状態、T字路への移動、回転、左右通路、扉の両方向通過、方向維持、部屋の三方の壁、前進による扉通過の禁止、別マップと独自の扉配列、翻訳を確認する。npm run buildで型検査と配布ビルドを行う。

Vite起動後のnpm run test:browserはChromiumで日本語／英語、A・B配置、タップ／矢印キー、扉の往復とログ、言語変更、320px幅の640／480／320／240px高さ、模擬Safe Areaを確認する。正面壁・側壁・扉の裏側に構造を追加しても画像が変化しないこと、開口部の先の構造は画像に反映されることをピクセル比較する。T字路、部屋の北側、部屋から見た扉のスクリーンショットを保存する。

実機のiOS Safari／Android Chromeと実際のノッチ・ブラウザバーの変化は別途確認が必要。

## 2Dオートマップ

初期表示は3D。Bで同じ表示枠を2Dマップに切り替え、再度Bで戻る。既存の表示枠、ログ、操作部の配置と方角ラベルは維持する。右側の固定ステータス欄も配置・内容を維持する。

src/automap.tsは3D描画から独立する。訪問履歴は既存座標の文字列キー（x,y）のSetで管理し、初期位置だけを登録する。通常移動・Aの扉通過によって座標が変化したときだけ移動先を追加する。回転・移動失敗・切替は追加しない。再訪は重複せず、履歴は表示切替後も保持する。再読み込み時の保存は行わない。

DUNGEON_MAPの訪問済み床のみを正方形で描画する。未訪問の床・壁・扉・輪郭線は描かない。北は上、東は右。320×200のSVG内で1マス32×32、訪問済み範囲が収まる場合はその範囲を中央に表示し、現在位置は背景色と30pxの↑→↓←で区別する。訪問済み範囲が表示窓を超える軸では同じ縮尺の表示窓が現在位置に追従し、範囲外の訪問済みセルを省略する。履歴自体は保持する。

マップ中は方向ボタンとAをdisabledにし、暗く表示する。イベント処理でも移動・回転・Aを拒否し、矢印キーも位置・向き・履歴・ログを変更しない。Bと言語切替は使用可能。表示枠とBのアクセシブルラベルは日英に対応し、Bはaria-pressedでマップ表示状態を伝える。

単体テストで訪問履歴・重複排除・未訪問非表示・正方形・固定方角を検証する。ブラウザテストで初期3D、B往復、通常移動と扉通過、操作拒否、状態とログの保持、言語切替、320pxとPCの表示切替前後のレイアウト一致を検証する。

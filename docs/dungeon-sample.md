# マップ、衝突、2.5D描画

16×16の既存マップをそのまま使う。`#` は通行可能な床、半角スペースは壁。左上が原点でXは右、Yは下。床は112セルあり、開始位置はセル(2,14)の中心(2.5,14.5)。方向角は北が0ラジアン、時計回りに増える。

```text
|                |
| ####     ##### |
| #### ######### |
| ####  #  ##### |
|  #    #  ##### |
|  ###########   |
|  #   ###   #   |
|  #   ###   #   |
| #### ###   #   |
| ####  #    #   |
| ####  #  ##### |
| ############## |
|  #       ##### |
|  #       ##### |
|  #           # |
|                |
```

## 連続移動と衝突

ワールド座標の各セルは1×1の範囲で、セル(n,m)の中心は(n+0.5,m+0.5)。プレイヤーの速度は2.4セル/秒、円形の当たり半径は0.2セル。`src/dungeon.ts` に定数を置く。入力ベクトルは長さ1へ正規化し、斜め方向で速度が上がらない。

移動量は時間に比例させ、最大0.08セル単位に分けて壁との円・矩形接触を確認する。XとYの移動を個別に適用し、片方が壁に当たってももう片方を進めることで壁沿いに滑る。外周、壁、閉じた扉をすり抜けない。描画結果は移動判定に使わない。

## 扉

扉は床セル間の境界にあり、初期状態はすべて閉じている。

| 通路側 | 部屋側 |
| --- | --- |
| (2,11) | (2,10) |
| (2,4) | (2,3) |
| (9,2) | (10,2) |
| (12,5) | (12,4) |
| (7,5) | (7,6) |
| (12,9) | (12,10) |

Aボタンは、扉の中央から1.25セル以内かつ正面±60度の扉を選び、開閉状態を切り替える。閉じた扉はプレイヤーと敵の移動、レイ描画、視線、経路探索のすべてを遮る。開いた扉は同じ判定ですべて通過できる。誰かが扉面に接触している間は閉じられない。開閉は簡易的で、状態をゲーム中に保持する。

描画用に `GameState.doorMotions` が直前の状態と開始ゲーム時刻を持つ。`openDoors` は従来どおり操作時に即時更新し、衝突、視線、経路探索、レイキャストの唯一の論理状態として使う。扉は黒い面と単純な緑の輪郭で壁から区別する。開くときは通路をすぐ表示し、扉の左右の線が中央から枠へ0.26秒で移る。閉じるときは不透明な面をすぐ表示し、左右の線が端から中央へ0.26秒で移る。アニメーションは表示上のアクセントで、通行可能性や深度を変えない。

## 2.5D Canvas描画

`src/renderer.ts` はCanvas 2Dで水平FOV約72度のレイキャストを行う。垂直カメラ移動、ジャンプ、高低差はなく、視点高さは固定。背景は黒一色を基本に、床と天井にはワールド座標へ固定した広い間隔の格子だけを投影する。格子線は壁の輪郭より暗くし、移動や旋回に合わせて自然に動かす。壁は不透明な黒い面と緑の外周・境界線で形を示し、少数の単純なパネル線を距離に応じて暗く描く。

各画面列のレイは壁または閉じた扉の最初の交差で止まり、列ごとの壁深度を保持する。敵はワールド位置から透視投影し、距離に応じて拡大縮小する。敵の画像は遠い順に `drawImage()` で重ね、壁または閉じた扉より奥の列を壁深度で隠す。透明画素はそのまま背景を通すため、手前の敵が後方の敵を覆っても輪郭の隙間は残る。立体装飾用の深度バッファは使わない。

敵の独立した透過PNGは `src/assets/mutant/` に置き、idle・walk・chaseを各4フレーム用意する。読み込み後の画像をキャッシュし、毎フレームの敵形状生成やピクセル読み戻しは行わない。アニメーションフレームは `GameState.time` から選ぶ。Canvas内部解像度は `devicePixelRatio` を最大2まで反映する。レイと視線の両方で角を通り抜けないsupercover判定は維持する。

## 探索マップ

訪問セルは連続座標の `floor(x), floor(y)` から記録する。同じセル内の移動では新しい場所を記録しない。メニューから表示するマップは全体を1:1のSVGで描く。訪問済みセルだけ床として表示し、壁線はそこから判明する境界に限る。開閉済みの扉を状態付きで描く。

視覚で見つけた敵はその位置と連続した向きの矢印、聴覚で見つけた敵は位置の輪だけを表示する。マーカーは現在の検知スナップショットから作る。マーカーのために未探索の床・壁を追加表示しない。

## エリア区分

既存の5部屋の範囲情報を維持し、その他の床を通路と扱う。

- 北西：(1–4, 1–3)
- 北東：(10–14, 1–4)
- 中央：(6–8, 6–8)
- 南西：(1–4, 8–10)
- 南東：(10–14, 10–13)

座標は両端を含む。別マップに部屋区分を推測適用しない。

描画比較、敵スプライトのフレーム一覧、性能測定、検証手順は[描画簡素化レポート](visual-review/README.md)を参照。

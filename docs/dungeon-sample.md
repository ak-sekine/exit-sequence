# マップ、衝突、2.5D描画

16×16の既存マップをそのまま使う。`#` は通行可能な床、半角スペースは壁。左上が原点でXは右、Yは下。床は112セルあり、開始位置はセル(2,14)の中心(2.5,14.5)。方向角は北が0ラジアン、時計回りに増える。

| ####     ##### |
| #### ######### |
| ####  #  ##### |
|  #    #  ##### |
|  ###########   |
|  #   ###   #   |
|  #   ###   #   |
| #### ###   #   |
| ####  #    #   |
| ####  #  ##### |

## 連続移動と衝突

ワールド座標の各セルは1×1の範囲で、セル(n,m)の中心は(n+0.5,m+0.5)。プレイヤーの速度は2.4セル/秒、円形の当たり半径は0.2セル。`src/dungeon.ts` に定数を置く。入力ベクトルは長さ1へ正規化し、斜め方向で速度が上がらない。

移動量は時間に比例させ、最大0.08セル単位に分けて壁との円・矩形接触を確認する。XとYの移動を個別に適用し、片方が壁に当たってももう片方を進めることで壁沿いに滑る。外周、壁、閉じた扉をすり抜けない。描画結果は移動判定に使わない。

## 扉

扉は床セル間の境界にあり、初期状態はすべて閉じている。

| 通路側 | 部屋側 |
| --- | --- |
| (2,11) | (2,10) |
| (2,4) | (2,3) |
| (9,2) | (10,2) |
| (12,5) | (12,4) |
| (7,5) | (7,6) |
| (12,9) | (12,10) |

Aボタンは、扉の中央から1.25セル以内かつ正面±60度の扉を選び、開閉状態を切り替える。閉じた扉はプレイヤーと敵の移動、レイ描画、視線、経路探索のすべてを遮る。開いた扉は同じ判定ですべて通過できる。誰かが扉面に接触している間は閉じられない。開閉は簡易的で、状態をゲーム中に保持する。

描画用に `GameState.doorMotions` が直前の状態と開始ゲーム時刻を持つ。`openDoors` は従来どおり操作時に即時更新し、衝突、視線、経路探索、レイキャストの唯一の論理状態として使う。閉じるときは論理状態と同時に不透明な隔壁を表示し、その面の補強線が0.26秒で閉位置へ移る。開くときは論理状態の更新と同時に通路を表示し、非不透明なパネル端の光が枠へ0.26秒で退避する。アニメーションは表示上のアクセントで、通行可能性や深度を変えない。

## 2.5D Canvas描画

`src/renderer.ts` はCanvas 2Dで水平FOV約72度のレイキャストを行う。垂直カメラ移動、ジャンプ、高低差はなく、視点高さは固定。床・天井の格子と点検パネルはセルのワールド座標からカメラへ投影し、移動・旋回時に床面や天井面へ固定して見せる。天井にはフレーム、区画、照明パネルを、床には排気口や点検ハッチを加える。背景はほぼ黒にし、塗りつぶしを抑えた緑の線と控えめな発光で構造を示す。

壁は黒緑で遠景を隠した後、レイ交差位置をセル座標と面方向で決定的に分類する。4種類の装甲パネル、二重継ぎ目、補強リブ、通気口、点検ハッチ、配線、点滅インジケーターを面内だけに描く。距離で線の明るさを下げ、通路形状と奥行きを保つ。セルの模様選択と床・天井の装飾一覧はキャッシュする。

各画面列のレイは壁または閉じた扉の最初の交差で止まる。描画距離を列ごとの深度バッファに保存し、敵スプライトの各画面列を壁と手前の敵の深度に照らして描く。透明なスプライト列は深度を奪わないため、敵の輪郭越しに後方の敵も見える。レイと視線の両方で角を通り抜けないsupercover判定を使う。敵スプライトは前後位置から射影し、遠い敵ほど小さくする。

外部3Dエンジンや画像素材は使わない。Canvasは端末のdevicePixelRatioを最大2まで反映する。敵は112×176の透明CanvasにCanvas Pathで骨格、頭部、歯、腕、爪、脚を線画合成する。敵ごとにCanvasを再利用し、深度判定用の不透明列マスクも同じ寸法で保持する。

## 探索マップ

訪問セルは連続座標の `floor(x), floor(y)` から記録する。同じセル内の移動では新しい場所を記録しない。メニューから表示するマップは全体を1:1のSVGで描く。訪問済みセルだけ床として表示し、壁線はそこから判明する境界に限る。開閉済みの扉を状態付きで描く。

視覚で見つけた敵はその位置と連続した向きの矢印、聴覚で見つけた敵は位置の輪だけを表示する。マーカーは現在の検知スナップショットから作る。マーカーのために未探索の床・壁を追加表示しない。

## エリア区分

既存の5部屋の範囲情報を維持し、その他の床を通路と扱う。

- 北西：(1–4, 1–3)
- 北東：(10–14, 1–4)
- 中央：(6–8, 6–8)
- 南西：(1–4, 8–10)
- 南東：(10–14, 10–13)

座標は両端を含む。別マップに部屋区分を推測適用しない。

# 移動・描画仕様

3D表示と操作を確認するサンプル。敵・感覚・ターン制は[enemy-ai.md](enemy-ai.md)を参照。アイテムとクリア判定はない。

## マップと境界

src/dungeon.tsのDUNGEON_MAPは16行×16列。#は床、半角スペースは通行不可。床は112マス、外周はすべて通行不可。

以下は両端の `|` を列境界として示す（`|` はマップデータに含めない）。各行の内部は半角16文字。

```text
|                |
| ####     ##### |
| #### ######### |
| ####  #  ##### |
|  #    #  ##### |
|  ###########   |
|  #   ###   #   |
|  #   ###   #   |
| #### ###   #   |
| ####  #    #   |
| ####  #  ##### |
| ############## |
|  #       ##### |
|  #       ##### |
|  #           # |
|                |
```

左上が原点、Xは右、Yは下。初期位置は(2,14)、北向き。北へ3マスで分岐(2,11)に到達し、正面の扉をAで通過すると南西の部屋(2,10)へ入る。facingは北0・東1・南2・西3。

北西（X=1〜4、Y=1〜3）、北東（X=10〜14、Y=1〜4）、中央（X=6〜8、Y=6〜8）、南西（X=1〜4、Y=8〜10）、南東（X=10〜14、Y=10〜13）の5部屋を通路で接続する。曲がり角、T字路、(7,2)付近の分岐、(6,2)・(2,14)・(14,14)の行き止まりがあり、中央の部屋を経由する道と東側の通路を回る迂回路を持つ。北西の部屋へは扉通過が必要。

DOORSは床セルとは別の境界情報で、6か所ある。

| from（通路側） | to（部屋側） |
| --- | --- |
| (2,11) | (2,10) |
| (2,4) | (2,3) |
| (9,2) | (10,2) |
| (12,5) | (12,4) |
| (7,5) | (7,6) |
| (12,9) | (12,10) |

doorBetweenは両方向から境界を判定する。すべて隣接する床マス間の境界で、重複はない。扉の開閉状態、タイマー、アニメーションは持たない。別マップには扉配列を明示的に渡せる。

上は1マス前進、左／右／下は座標を変えず90°左／90°右／180°回転。通常のmoveは床以外、マップ外、扉境界への前進を阻止する。AはpassDoorで正面の隣接扉を判定し、位置を直接1マス更新する。向きは維持する。開ける・通過・閉める処理は1回の操作で完了し、常に閉じた扉として描画する。正面に扉がなければAは状態もログも変更しない。Bは3D／2Dの2状態を切り替える。

## 描画

src/renderer.tsは閉じた境界を越えずに現在位置から到達できる床領域を抽出し、その壁境界と扉境界を求め、プレイヤーの座標・向きからカメラ座標へ変換する。壁面の平面で空間を分割するBSPにより、カメラから遠い側から手前へ描く。近クリップ面で切り取り、x/z、y/zで透視投影する。壁面をダンジョン背景色で塗り、緑色の輪郭線を描くことで奥の線を遮蔽する。正面壁、左右壁、閉じた扉の裏側は見えず、床同士の開口部には壁面を置かないため、実際に見える左右通路は表示される。特定のT字路に依存しない共通処理。

扉は壁面に長方形の枠、内部の横線、取っ手を描く。境界は一度だけ描画し、どちらの側からも同じ閉じた扉が見える。Aの移動直後にmain.tsが移動先のSVGを更新する。外部3Dライブラリは使用しない。

main.tsは入力、画面更新、言語メニュー、ログ追加を担当する。描画座標は移動判定に使わない。

## ログ

初期「通路にいる。」と前進不可「これ以上進めない。」を保持する。通常の前進成功、90°左／右回転、180°回転はGameState.logsに蓄積せず、画面にも追加しない。これらの操作でもターン進行、敵AI、成功移動時の音の生成、敵の検知、訪問履歴、ゲームオーバー判定は従来どおり行う。敵の視覚・聴覚検知とゲームオーバーのログも保持する（[enemy-ai.md](enemy-ai.md)参照）。

扉通過時だけ「扉を開けて部屋に入った。」「扉を開けて通路に戻った。」を追加する。英語はそれぞれ「Opened the door and entered the room.」「Opened the door and returned to the corridor.」。言語変更でGameState.logsの既存ログも再翻訳する。通常移動・回転は履歴にないため、言語変更後も復活しない。

### 3D描画時間の確認

同一環境のNode.jsで、全床×4方向を3周ウォームアップ後に10周計測した。旧5×5は360回、新16×16は4480回。renderDungeonの中央値は旧0.018ms／新0.253ms、95パーセンタイルは旧0.103ms／新0.457ms、新マップの最大は2.751msだった。床増加によって処理時間は増えるが、この環境では1回あたり1ms未満（95%）に収まる。SVG生成のみの計測で、実機ブラウザの描画時間を保証するものではない。

## 2Dオートマップ

初期表示は3D。Bで同じ表示枠を2Dマップに切り替え、再度Bで戻る。既存の表示枠、ログ、操作部の配置と方角ラベルは維持する。右側の固定ステータス欄も配置・内容を維持する。

src/automap.tsは3D描画から独立する。訪問履歴は既存座標の文字列キー（x,y）のSetで管理し、初期位置だけを登録する。通常移動・Aの扉通過によって座標が変化したときだけ移動先を追加する。回転・移動失敗・切替は追加しない。再訪は重複せず、履歴は表示切替後も保持する。再読み込み時の保存は行わない。

DUNGEON_MAPの訪問済み床のみを24×24（SVG座標）の正方形で描画する。SVGのviewBoxは320×200のまま、未探索領域と空間は黒（#000）、訪問済み床は暗い緑（#123c24）とする。各マスの枠線は描かず、つながる床を連続して表示する。現在位置は明るめの床（#245c38）と白緑（#e5fff0）の方向矢印で示す。矢印は幅12・高さ14の図形を中心で回転し、24×24のマス内に収める。北は上、東は右。表示中心はプレイヤー・訪問履歴とは独立したワールド座標で管理する。Bで開くたび現在のプレイヤー位置を基準に初期化し、ダンジョン全体の寸法で制限する。表示枠より小さい軸はダンジョン中央に固定する。大きい軸は表示枠が外周を越えない範囲で中心を制限する。マップサイズは行数・最大列数から取得する。範囲外のセルは省略し、履歴は保持する。

訪問済み床の北・東・南・西をisFloorで独立判定し、通行不可またはマップ外の境界だけに明るい緑（#4ade80）、幅2の実線を描く。通行可能な隣接床は未訪問でも壁線を描かず、その未訪問床自体も表示しない。DOORSとdoorBetweenで訪問済み床に接する扉を判定し、境界中央に隙間のある平行二重線で表す。扉境界には通常の壁線を重ねない。境界中央のワールド座標で重複を排除し、両側から同じ位置・向きに表示する。通過後も扉情報は保持する。未訪問床自体の輪郭や遠方の壁・扉は描かない。

マップ中は方向ボタンを有効にし、↑／↓／←／→および矢印キーで表示中心を北／南／西／東へ1マス（SVG座標24）移動する。端では移動量を制限する。プレイヤー移動処理は呼ばず、位置・向き・訪問履歴・ログ・固定ステータスの方角を変更しない。Aだけdisabledにし、イベント処理でも拒否する。方向ボタン付近の操作説明文は表示しない。説明用DOM・表示処理・CSS・翻訳定義は持たず、方向ボタンのaria-labelとtitleは日英・表示モードに応じて切り替える。方向ボタンとA／Bのサイズ・配置は維持する。言語変更・再描画でも表示中心を保持する。3Dへ戻ると方向操作は通常の移動・回転に戻る。プレイヤー矢印は実際の位置に描き、領域外なら省略し、領域端ではSVGでクリップする。Bと言語切替は使用可能。表示枠とBのアクセシブルラベルは日英に対応し、Bはaria-pressedでマップ表示状態を伝える。

単体テストで訪問履歴・24×24の床・床色・四方向の実際の壁・開口部・扉の向きと両側一致・重複排除・未訪問非表示・矢印・表示中心の移動・外周制限・小さい軸の固定・領域外の矢印非表示を検証する。ブラウザテストで初期3D、B往復、通常移動と扉通過、スクロールとAの操作拒否、状態とログの保持、言語切替、320pxとPCの表示切替前後のレイアウト一致を検証する。

## 検知した敵の2D表示

GameState.detectionsは敵IDを付けたSight／Hearingの現在ターンのスナップショット。初期は空で、敵行動後のプレイヤー感覚判定で毎ターン全件を置き換える。同時成立は視覚のみ保持し、検知できなかった敵は除外する。ログ履歴や敵AIの実座標・向きから表示情報を補完しない。視覚の向きを次の聴覚検知へ引き継がない。

視覚は検知座標に淡い赤（#fb7185）の方向矢印を表示する。敵自身の絶対方角（北=上、東=右、南=下、西=左）を使い、プレイヤーと同じ幅12・高さ14のSVG図形とする。聴覚のみは音源座標に半径7・線幅2の同色の○を表示し、方向の装飾は付けない。いずれも24×24マス内に収まる。白緑（#e5fff0）のプレイヤー矢印は変更せず最後に描き、重なった場合も視認性を保つ。新しいUI領域や凡例は追加しない。

未訪問マスでも検知マーカーだけは表示し、床・壁・扉は公開しない。既存のマップ座標変換と320×200のviewBoxを使い、中心が表示範囲外のマーカーは省略、端はSVGでクリップする。スクロールで範囲内に戻れば保持中の同じ検知状態で表示する。

最後に完了したターンの検知結果を次のゲームターンまで保持する。Bによる3D／2D切替、マップスクロール、言語切替、メニュー操作では敵行動も再判定も行わない。3Dで得た検知結果も2Dへ切り替えた際に表示する。捕獲ルールは維持し、プレイヤーが敵へ入った場合はそのターンの検知を空にして直ちに終了する。敵がプレイヤーへ入った場合は既存どおりそのターンの感覚判定を完了する。ゲームオーバー後は敵と検知状態を更新しない。

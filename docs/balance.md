# ゲームバランス測定

バランス比較は自動進行シミュレーションによる初期測定です。戦略性や面白さの証明ではありません。人間のプレイテストは別途必要です。

## 条件

`npm run simulate` はシード `1592590336` から連続する12,000シードを各方針に使い、同じゲーム乱数列とスロット乱数列で比較します。区画状態、イベント、観測はゲーム用乱数列、停止数字とランダム方針の選択はそれぞれ別のシード付き列を使います。成功率は観測ベースの整数へ丸め、シミュレーションでも停止数字との比較で判定します。

比較する方針:

- 一様ランダム：選択肢を等確率で選ぶ。
- 常に選択肢1：イベントの最初の行動を選ぶ。
- 失敗時の損失が最小：失敗差分が最も大きい行動を選ぶ。
- 成功時の回収が最大：成功差分が最も大きい行動を選ぶ。
- 手掛かり・生存重視：観測から表示成功率を推定し、期待電力と生存確率をスコア化する。

## 測定値

測定値は `npm run simulate` の出力から記録します。

| 方針 | クリア率 | 終了時電力のP10 / P50 / P90 | クリア時平均電力 | 平均停止マス |
| --- | ---: | ---: | ---: | ---: |
| 一様ランダム | 30.5% | 0 / 0 / 14 | 11.05 | 10.85 |
| 常に選択肢1 | 57.5% | 0 / 5 / 19 | 11.93 | 13.03 |
| 失敗時の損失が最小 | 79.0% | 0 / 8 / 18 | 10.75 | 14.39 |
| 成功時の回収が最大 | 9.1% | 0 / 0 / 0 | 12.14 | 7.51 |
| 手掛かり・生存重視 | 87.7% | 0 / 13 / 20 | 13.24 | 14.62 |

一様ランダムでは約7割が失敗し、成功時の回収だけを狙う方針は約1割に留まりました。電力リスクを見た方針では約8割、観測を使う方針では約88%がクリアしています。進行可能な方針はありますが、ランダム選択は厳しめです。今後の人間プレイテストでは、ログから手掛かりを学び取れるか、序盤の連続失敗が理不尽に感じないかを確認します。

数値はこのシード集合と現在のモデルに依存します。方針を理解しやすくする調整や実際のプレイ体験を代替しません。

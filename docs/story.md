# 物語設定

ロボットたちは感情豊かに暮らし、街には比較的安全な生活圏がある。街の外には長く使われていない廃墟や廃棄施設が点在し、かつて働いていたロボットたちの設備や部品が残る。危険なミュータントは以前から廃墟に多数生息しており、探索は危険な仕事だ。

主人公はスカベンジャーのロボット。好奇心旺盛で少し子どもっぽく、部品の値打ちを気にしながら廃墟を探る。前向きだが怖いものは怖い。失敗すると文句を言い、それでも街へ帰るために頑張る。

いつもの部品探しの最中に床が抜け、主人公は廃棄施設の最深部まで落ちた。限られた電力で設備を越え、ミュータントに会う前に地上へ脱出して、安全なロボットの街へ帰ることが目的。

15マスは3段階で上昇する。1〜5マスは廃棄物の多い最深部、6〜10マスは保守・搬送設備の中層、11〜15マスは外の光や風が近い上層。プレイ中の短い説明と各設備とのやり取りで世界観が少しずつ分かる。

CLEARでは地上へ出て街へ帰る喜びを描く。GAME OVERは電力切れによる一時停止として描き、主人公が充電器を呼ぶ。ミュータントとの戦闘や敵AIは登場しない。

## イベントの文章作成ルール

### イベント説明文

- 主人公の視点を中心にし、状況・設備・選べる行動が自然に伝わるようにする。
- 感情豊かなロボットだけが暮らす世界観に合わせ、明るくコミカルな文体を保つ。
- 説明を長くしすぎず、行動選択に必要な情報を短く伝える。

### 成功文

- 選んだ行動が成功したと分かる描写にする。
- 描写と実際の電力変化を一致させる。成功時にも電力を消費する行動があるため、「成功＝充電」と決めつけない。
- 主人公の喜びや反応を表し、短く読みやすくする。

### 失敗文

- 選んだ手段で期待した結果を得られなかったことを明確にする。失敗は必ずしも移動失敗を意味しない。
- 電力の増減と描写を一致させる。電力を失う結果なら消耗が伝わる表現にする。
- 電力が残っている失敗後も次のマスへ進めるルールと矛盾させない。障害物の突破に失敗した場合も、別経路や別の通過方法があり得ると伝わるようにする。
- 失敗文だけで完全に進行不能、永久に足止め、脱出済みと確定させない。失敗直後に次の場所へ移動したと断定しない。
- 電力が0になってGAME OVERとなる場合にも成立させる。移動継続を断定せず、可能性や探索の余地として描く。
- 過度に悲惨な描写を避け、主人公の感情とユーモアを入れる。同じ決まり文句を使い回さず、簡潔にする。
- 充電・回収の失敗は回収できなかった描写だけでもよい。設備に留まり続ける必要があるように書かない。

### 新イベント追加時のレビュー

新イベントは全行動について、成功文・失敗文、成功時と失敗時それぞれの電力差分との整合性、成功後と失敗後の次イベントへの接続、電力0のGAME OVERとの整合性、コメディ調と世界観との整合性をレビューする。失敗文の意味は自動テストだけでは判定できないため、人による文章レビューを必須とする。イベント一覧のチェック項目は [イベント一覧](event-catalog.md) を参照。

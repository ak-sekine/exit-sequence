# ゲームルール

- 15マス、3区画を進む。1〜5マスは最深部、6〜10マスは中層、11〜15マスは地上に近い上層。
- 各マスで10種類のイベントから一つを一様抽選する。各イベントには3つの行動がある。
- 行動ごとに固定の整数成功率、成功時の電力差分、失敗時の電力差分を表示する。
- スロットの停止数値が成功率未満なら成功。表示値と同じ数値なら失敗する。
- 行動の結果に応じた個別文章と、上限20・下限0を反映した実際の電力変化を表示する。
- 結果が出たら「次へ進む ▶」で次のマスへ進む。成功・失敗ともにこの待機を行う。
- 電力が0になるとGAME OVER。15マス目を電力が残った状態で終えるとCLEAR。
- 終了状態と電力は最後の行動判定時に確定するが、CLEAR・GAME OVERの場面は最後の行動結果全文が表示された後、進行操作を受けてから表示する。終了待機中にPOSITIONやPOWER、イベント抽選は変化しない。
- 失敗しても電力が残れば次へ進める。ロボットの電力切れは冒険の中断であり、死亡を意味しない。
- イベント抽選はシードで再現できる。スロット演出の乱数はイベント抽選系列に影響しない。
- プロローグ終了後、通常イベント結果後、終了結果後は共通の「次へ進む ▶」操作を使う。文字送り中のタップはスキップだけで、スクロールや「最新ログへ」は進行しない。Reduced Motionでも進行待ちを維持する。
- ゲーム開始時はPOSITION 01/15・POWER 20/20を保ったままプロローグを表示する。全文表示後に「次へ進む ▶」、タップ、Space、Enterのいずれかを受けて、`createGame()` が抽選済みの初回イベントを表示する。プロローグ表示・待機はイベント抽選やゲーム進行を行わない。

## 表示と操作

画面上部にはPOSITIONとPOWERを表示し、プロローグ画像とイベント画像はログに追加して履歴に残す。プロローグ全文の表示をスキップした入力ではイベントに進まず、全文表示後の入力を待つ。文章は10ms/文字で表示し、ログをタップすると全文を表示する。スロットは00〜99で回転し、タップ・クリック・Enter・Spaceで停止できる。結果後は明示的な続行操作が必要。ログのスクロール、320px幅、Reduced Motionに対応する。

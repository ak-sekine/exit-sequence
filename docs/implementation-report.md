# RPGプロトタイプ：実装と検証

取得した最新origin/main `8fd9b2d97dc122dd78c32c7ff29d402a7f5a62ef`からmain上で実装。原因発見のデータとルールを置換し、並存させていない。

基本ループは探索 → 戦闘／能力イベント → 戦利品 → 成長 → 次区画。居住区、整備区画、帰還船ドックの3区画。必須戦闘3、工具倉庫の任意戦闘1。各区画の寄り道は医務室（回復・キット・記録）、倉庫（戦闘後にツール選択）、更衣室（ベスト・回復・記録）。各寄り道は一回のみ。寄り道なしも全ビルドCLEARを確認。

BODY/TECH/SENSE各1、開始時追加2ポイント。BODYは近接と防御、TECHは機械干渉、SENSEは次行動ボーナスと照準解除、物資発見。HP12から開始、0でGAME OVER。能力イベントは3方式すべて突破できる。瓦礫、昇降路、船への荷物を能力で処理し、能力1/2/3以上はそれぞれHP-2/-1/0。BODYはキット、TECHはHP+2、SENSEはバッテリーの報酬。

完全ターン制。敵名、HP、次行動とダメージを常時予告。攻撃はBODY+1、技術はTECH。閉装甲とスキャンでは攻撃最大1。技術は装甲を開きスキャンを中止、連続使用は遮断。観察はSENSE+1を次の攻撃／技術へ加算し、スキャン中は照準を外す。防御は5+floor(BODY/2)軽減。アイテム選択の開閉は非進行、使用は1ターン。撃破時は敵反撃なし、キットを回収。敵の強攻撃を技術でキャンセルはできない。BODY5＋レンチ＋ベスト、TECH5＋端末＋ベスト、HP16でも攻撃／技術だけの連打はボスに敗北するテストを追加。

整備ロボットHP8はアーム→強攻撃7→回復。警備HP12は装甲→スキャン→射撃（4、照準8）→回復。ボスHP19は装甲→スキャン→射撃→強攻撃10→回復2回。ボスは装備済みの攻撃連打も防御なしでは生存できないようにし、組み合わせる経路は5～8ターンを目指した。

6品：工具レンチ（攻撃+1）、診断端末（技術+1）、センサーバイザー（観察+1）、防護ベスト（ダメージ-1）、応急キット（HP+6）、スタンバッテリー（敵行動1回停止）。ツール1枠、防具1枠。キット上限3、バッテリー上限2。LV2/3で最大HP+2、HP+4、能力1ポイント。最終最大HP16。

## 3ビルド結果

各ビルドは初期2ポイントと成長2ポイントを同じ能力へ配分。全寄り道を探索。日英は同じ状態と結果。Chromiumでも実際の320×640タッチ操作で各言語3周を実行。

| ビルド | 終了能力 | 装備 | CLEAR時HP | 戦闘ターン（居住区／倉庫／警備／ボス） |
| --- | --- | --- | --- | --- |
| BODY | 5 / 1 / 1 | レンチ＋ベスト | 12/16 | 3 / 3 / 5 / 7 |
| TECH | 1 / 5 / 1 | 端末＋ベスト | 12/16 | 4 / 3 / 4 / 8 |
| SENSE | 1 / 1 / 5 | バイザー＋ベスト | 9/16 | 7 / 6 / 9 / 7 |

BODYは観察後の近接、TECHは連続干渉を避けつつ技術、SENSEは観察ボーナスを防御中も保持して攻撃に使う。射撃／強攻撃時には防御へ切り替える。SENSEはイベントでバッテリーが増える。最終キット3、バッテリーはBODY/TECHが1、SENSEが2。この参照経路は消耗品を節約する例。回復とスタンの効果は別の単体／ブラウザ操作で確認する。

## 検証

`npm test`、`npm run build`、`git diff --check`成功。単体はキャラ作成、能力上昇、HP増減／上限、HP0、5基本行動、予告更新、撃破報酬、敵周期の違い、ボス、6品効果、3イベント方法、成長、3ビルドCLEAR、ja/enロジック一致、無効操作、状態コピー、イベント中のHP0を成長回復より先に判定、restart、寄り道なしCLEAR、単一行動連打敗北を確認。

## 準備と結果

型付きのchallengeごとのpreparation、observations、attempts、outcomeを導入。ロボットの手元と足場、気密の固定と管、昇降の電源と解除方法、船の圧力・電源・準備灯を分けた。準備するだけでは突破しない。

結果はclean / costly / retreat / failureとして内部に保持し、文章で表す。光＋低い姿勢なら追加消費と負傷なし。箱の誘導は箱と少量の空気を使い、周期だけを使う方法は待つ空気を使う。漏れを待つ気密、手動の昇降も通過できるが代償が残る。

再挑戦は一時準備だけを戻す。記憶、負傷、空気、警戒、消耗は保持する。修理・交換済みの管は撤退しても残り、固定と均圧だけが解除される。船の修正は有効な状態を保持するか、圧力を解除して扱い直すかを選べる。

## 失敗から学ぶ例

ライトだけを準備し、直立で実行すると、赤い走査は止まるが腕は頭の高さを横切る。軽い負傷と空気の代償で扉へ戻る。主人公は「止まったのは、赤い光だけか」、AIは「実験結果としては、そう見えますね」と返す。

次に低い姿勢を組み合わせると、腕が背中の上を通り、追加損失なしで突破する。前に退いた場所を通り、新しい痛みが増えなかったことを描く。AIは攻略の答えを読み上げない。

均圧だけなら針が戻る。青い電気が来てもブレーキの爪が残れば台は動かない。外部接続の点火では線が赤く点滅する。各結果は、今回見えた事実と残った表示から原因を推測できる。

## ItemとKnowledge

- ライト：走査への照射、薄い船の票を読む時間の節約。
- 工具：管の修正、ブレーキの固定、船のケーブルを短時間で外す。
- 箱：奥で音を出す誘導、丸い穴へ当てる振動。実行時に一度だけ消費。
- 予備酸素：スーツへ補給、気密の補助管へ接続。接続時に一度だけ消費。

回収済みの消耗品を棚から取り直せない。未使用の箱は準備変更・撤退で残る。Knowledgeは観測した事実と再認識のために保持し、Choiceの表示・成功判定には使わない。後で得た情報を過去ログへ逆流させない。

## 総当たりとOVER

危険な試行には空気、負傷、警戒、消耗品の代償。同じ困難で3回目以降の試行は疲労で追加の空気を使う。危険な観察の繰返しは空気と警戒を増やす。準備の組み替えや安全な表示確認は自由だが、資源は増えない。

OVERは累積空気浪費、重い負傷後の追加負傷、明示された危険な封印解除の3種。普通の最初のミスは修正可能。累積消耗のOVERはCLEARより優先し、操作が未完了なら成功文章と結果を残さない。

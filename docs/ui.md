# 画面と操作

## 表示

画面を3領域に分け、黒背景、明るい緑1色の文字、等幅フォントのコンソールとして表示します。タイトルは18px、位置と電力は15pxです。上部の固定ステータスには `EXIT SEQUENCE`、現在位置（`03 / 15` の形式）、現在の電力（`15 / 20` の形式）を表示します。中央のログが残りの高さを使い、下部の選択欄は画面下に固定します。ログにはイベント、説明、観測、行動履歴、結果を時系列で追加します。位置と現在電力は上部に表示するため、ログへ重複して出しません。行動結果による電力の増減と上限・下限の補足はログに残します。

新しく追加するログは基本10msごとに1書記素ずつ表示します。表示済みログを再アニメーションしません。ログはランの間保持され、中央の領域だけを縦にスクロールして確認できます。プレイヤーが末尾付近を見ている場合は新しい文字に合わせて自動スクロールし、過去ログを読んでいる場合は位置を保ちます。「最新ログへ」で末尾に戻れます。

行動の成功率、隠れた区画状態、乱数シードは表示しません。選択肢には既存の行動名・説明と、成功・失敗時に適用される電力差分を表示します。選択欄の見出しは14px、行動名は15px、説明と電力差分は14pxで、補足だけを小さくして詰め込まないようにします。成功・失敗・クリア・ゲームオーバーも文字色は変えず、`[SUCCESS]`、`[FAILED]` などの表示で区別します。

## 文字送りと入力

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 文字送りをスキップ | コンソールをクリック、`Space`、`Enter` | コンソールをタップ |
| 行動を選択 | 選択肢をクリック、または `1`・`2`・`3` キー | 選択肢の行をタップ |
| 最新ログへ戻る | 「最新ログへ」をクリック | 「最新ログへ」をタップ |
| 終了後に再挑戦 | 再スタート行をクリック | 再スタート行をタップ |

イベント説明と観測情報の文字送りが終わると、下部に3つの選択肢を説明・電力差分まで一度に表示し、ログ末尾の `>` と点滅カーソルも同時に表示します。選択肢の表示を待つ文字送りはありません。選択待ち中は直ちに行動を選べます。行動を選ぶとログ末尾の `>` の後ろに番号と行動名を1文字ずつ表示して確定し、その表示完了後に結果を出します。選択した入力は過去ログとして保持します。次のイベントでは新しい `>` 行を追加します。下部の選択欄にプロンプトやカーソルは表示しません。

中央ログの出力中は行動入力を受け付けません。スキップは待っているログ文字の表示だけを完了し、行動、乱数判定、電力消費、イベント進行を行いません。PCの数字キーはイベントログ完了後、選択肢が表示された時点から使えます。`prefers-reduced-motion: reduce` が有効な場合は中央ログの文字送りを省略して全文を即時表示し、入力欄も同じタイミングで表示します。非表示タブでは出力を一時停止し、復帰時に続きから再開します。

中央ログの出力はゲームロジックと分離したキューで順番に処理します。下部の入力欄はこのキューを使わず、イベントログ完了時に選択肢全体を同期表示します。選択履歴の確定と行動判定も分け、行動名の文字送りが終わってから判定を実行します。文字の追加ごとにログ領域全体を作り直さず、スクリーンリーダーには文字単位の大量通知を送らない設定です。再スタート時は旧キューとカーソルを消し、ログを消去して新しいランを始めます。

## レスポンシブ対応

幅320px以上のスマートフォン縦画面を優先し、横スクロールなしで長い日本語を折り返します。上部ステータスと下部コマンド選択はGridの固定行に配置し、中央ログだけを残りの高さで縦スクロールさせます。入力欄は画面サイズに応じた高さを持つ内部スクロール領域で、ログ出力中も位置を保ちます。短い横画面や320px幅で選択肢が収まらない場合も、入力欄内をスクロールして全てにアクセスできます。選択肢のタップ領域は高さ44px以上です。iPhoneのSafe Areaを反映し、PCでは最大幅760pxで中央に配置します。

ブラウザテストは320×640、390×844、1280×800、812×375で、ステータス・ログ・入力欄の実測位置、領域同士の重なり、画面外への横はみ出し、固定文字サイズ、緑文字、選択欄の内部スクロールを確認します。イベント説明中に入力できないこと、説明完了後に全文の選択肢が一度に表示されること、タップ、マウス、数字キー、ログのスクロール、文字送りのスキップ、Reduced Motion、再スタートも操作します。テストのChromiumはブラウザ自動化による確認です。実機のiPhone SafariやAndroid端末では検証していません。

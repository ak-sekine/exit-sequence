# UI仕様

- 上部にPOSITIONとPOWERのみを固定表示。
- 起動・再スタート時はマンガ調PNGの `public/story/prologue.png` をログへ表示し、導入文の全文表示後に「次へ進む ▶」で初回イベントへ進む。待機中はイベント内容と行動選択肢を表示しない。
- プロローグ画像はイベント画像と別の種別としてログに残し、イベント画像数には含めない。画像枠は読み込み前に320×200で確保する。
- イベント見出し、画像、短い説明をログに追加。観測行は表示しない。
- 10ms/文字、ログのタップで文字送りをスキップ。
- 行動選択後に表示成功率をログへ出し、00〜99のスロットを回転。
- スロット停止値を表示率と比較し、個別の結果文章と実電力変化を記録。
- 成功・失敗どちらも「次へ進む ▶」を表示して進行待ち。プロローグでも同じボタンを使い、タップ・Space・Enterでも進行できる。
- 最後の行動結果も全文表示後に「次へ進む ▶」を表示する。終了状態と実際の電力は判定時に確定するが、CLEAR/GAME OVER見出し・画像・文章は進行操作まで表示しない。
- 進行操作後は終了見出し、専用PNG画像、文章の順にログへ追加する。画像は文字送りせず寸法を先に確保し、文章は10ms/文字で送り、画像と文章をログ履歴に残す。読み込み失敗でも操作を継続する。
- 終了文章の全文表示後にだけ `[R] 新しいシーケンスを開始` を表示する。文字送りスキップは再スタートを実行せず、画像は各エンディングにつき一度だけ表示する。
- 15回のイベント画像をログ履歴に残す。区画移動で短い物語メッセージを加える。
- 黒背景、緑文字、320px幅対応、縦横スクロール、Reduced Motion対応。
- CLEAR/GAME OVER後は物語の結末と再スタート操作を表示。
- エンディング画像はイベント画像とは別種別にし、イベント画像数に含めない。最大幅320px・8:5、812×375では高さに合わせて縮小する。
- プロローグ、イベント10種類、CLEAR、GAME OVERの画像は黒背景・緑線のみの320×200 PNGマンガ調線画です。制作仕様は[画像制作仕様](art-style.md)を参照。UIの黒背景・緑文字は維持する。

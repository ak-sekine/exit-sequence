# UI仕様

- 上部にPOSITIONとPOWERのみを固定表示。
- イベント見出し、画像、短い説明をログに追加。観測行は表示しない。
- 10ms/文字、ログのタップで文字送りをスキップ。
- 行動選択後に表示成功率をログへ出し、00〜99のスロットを回転。
- スロット停止値を表示率と比較し、個別の結果文章と実電力変化を記録。
- 成功・失敗どちらも「次へ進む ▶」を表示して進行待ち。
- 15回のイベント画像をログ履歴に残す。区画移動で短い物語メッセージを加える。
- 黒背景、緑文字、320px幅対応、縦横スクロール、Reduced Motion対応。
- CLEAR/GAME OVER後は物語の結末と再スタート操作を表示。

# 画面と操作

## 表示

画面全体を黒背景、緑文字、等幅フォントのコンソールとして表示します。上部の固定ステータスには `EXIT SEQUENCE`、現在位置（`03 / 15` の形式）、現在の電力（`15 / 20` の形式）を表示します。イベントパネルやカード型の選択肢は使わず、イベント、説明、観測、行動結果、電力、移動をコンソールログへ時系列で追加します。

新しく追加するログは基本10msごとに1文字ずつ表示します。日本語を含む文字列は書記素単位で扱い、表示済みログを再アニメーションしません。ログはランの間保持され、中央の領域を縦にスクロールして確認できます。プレイヤーが末尾付近を見ている場合は新しい文字に合わせて自動スクロールし、過去ログを読んでいる場合は位置を保ちます。「最新ログへ」で末尾に戻れます。

行動の成功率、隠れた区画状態、乱数シードは表示しません。選択肢には既存の行動名・説明と、成功・失敗時に適用される電力差分を表示します。

## 文字送りと入力

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 文字送りをスキップ | コンソールをクリック、`Space`、`Enter` | コンソールをタップ |
| 行動を選択 | 選択肢をクリック、または `1`・`2`・`3` キー | 選択肢の行をタップ |
| 最新ログへ戻る | 「最新ログへ」をクリック | 「最新ログへ」をタップ |
| 終了後に再挑戦 | 再スタート行をクリック | 再スタート行をタップ |

出力中は選択肢を無効にし、表示が終わった後に入力を受け付けます。スキップは待っている文字の表示だけを完了し、行動、乱数判定、電力消費、イベント進行を行いません。PCの数字キーは選択肢が有効な間だけ使えます。`prefers-reduced-motion: reduce` が有効な場合は文字送りを省略し、全文を即時表示します。非表示タブでは出力を一時停止し、復帰時に続きから再開します。

出力待ちテキストはゲームロジックと分離したキューで順番に処理します。文字の追加ごとにログ領域全体を作り直さず、スクリーンリーダーには文字単位の大量通知を送らない設定です。再スタート時は旧キューを停止し、ログを消去して新しいランを始めます。

## レスポンシブ対応

幅320px以上のスマートフォン縦画面を優先し、横スクロールなしで長い日本語を折り返します。上部ステータスと下部コマンド選択を固定し、中央ログを残りの高さに配置します。選択肢のタップ領域は高さ44px以上です。Safe Area を反映し、PCでは最大幅760pxで中央に配置します。

ブラウザテストは320×640、390×844、1280×800、812×375で幅超過と選択領域を確認し、タップ、マウス、数字キー、ログのスクロール、文字送りのスキップ、Reduced Motion、再スタートを操作します。テストのChromiumはブラウザ自動化による確認です。実機のiPhone SafariやAndroid端末では検証していません。

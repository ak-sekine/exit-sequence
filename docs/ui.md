# 画面と操作

## 表示と配色

画面は上部の固定ステータス、中央のログ、下部の入力欄の3領域です。背景は黒系、文字はタイトル、本文、ステータス、選択肢、電力差分、カーソル、「最新ログへ」、再スタートまで濃い緑 `#4fd66a` に統一しています。成功・失敗・クリア・ゲームオーバーも色を変えず、ログの文言で区別します。枠線とホバー背景には暗い緑を使います。

タイトル `EXIT SEQUENCE` は上端の左側に固定します。その下は左にイベント設備画像、右に現在位置と電力を置く2列です。イベント画像は同じ黒背景と緑系の陰影で描いたローカルSVGで、金属の面、反射、陰影や細部を加えています。10イベントそれぞれに個別の設備画像を用意し、通常のスマートフォン幅では幅136px、PC幅では幅144〜160pxで表示します。短い横画面では高さを確保するため幅を縮めます。表示する画像は公開用 `GameView.currentEvent.id` だけで選び、確率や内部状態はビューへ追加しません。

基本の文字サイズは、タイトル18px、位置と電力16px、ログ本文15px、選択肢の行動名15px、電力差分14px、「最新ログへ」14px、再スタート15pxです。画面幅や高さが小さい場合も文字サイズを14px未満にはしません。

中央ログはイベント、説明、観測、選択履歴、結果を時系列に追加し、位置と電力は上部にだけ表示します。新しいログは基本10msごとに1文字ずつ表示し、表示済みのログは再アニメーションしません。ログはランの間保持され、中央の領域だけを縦にスクロールして読み返せます。末尾付近を見ている場合は新しい文字に合わせて自動スクロールし、過去ログを読んでいる場合は位置を保ちます。「最新ログへ」で末尾に戻れます。

下部には見出しを置かず、3つの選択肢を1行ずつ表示します。選択肢と電力差分はイベント画像・ログの表示中も即時に表示し、中央ログの出力が終わるまで操作を無効にします。各行には行動名と成功時・失敗時の電力差分（例：`+5/-4`）だけを表示し、説明文と `[SELECT ACTION]` は表示しません。行動名を省略せず、320px幅でも各行44px以上のタップ領域を保ちます。選択待ちになるとログ末尾に `>` とカーソルを出します。

## 文字送りと入力

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 文字送りをスキップ | コンソールをクリック、`Space`、`Enter` | コンソールをタップ |
| 行動を選択 | 選択肢をクリック、または `1`・`2`・`3` キー | 選択肢の行をタップ |
| 最新ログへ戻る | 「最新ログへ」をクリック | 「最新ログへ」をタップ |
| 終了後に再挑戦 | 再スタート行をクリック | 再スタート行をタップ |

行動を選ぶとログ末尾の `>` と同じ行へ番号と行動名を文字送りして確定し、表示完了後に結果を出します。選択した入力は過去ログとして保持します。次のイベントでは新しい `>` 行を追加します。下部の選択欄にはプロンプトやカーソルを表示しません。

出力中は選択肢を無効にし、表示が終わった後に入力を受け付けます。スキップは待っている文字の表示だけを完了し、行動、乱数判定、電力消費、イベント進行は行いません。PCの数字キーは選択肢が有効な間だけ使えます。`prefers-reduced-motion: reduce` が有効な場合は文字送りを省略し、全文を即時表示します。非表示タブでは出力を一時停止し、復帰時に続きから再開します。

出力待ちテキストはゲームロジックと分離したキューで順番に処理します。選択履歴の確定と行動判定も分け、行動名の文字送りが終わってから判定を実行します。文字の追加ごとにログ領域全体を作り直さず、スクリーンリーダーには文字単位の大量通知を送らない設定です。再スタート時は旧キューとカーソルを消し、ログを消去して新しいランを始めます。

## レスポンシブ対応

幅320px以上のスマートフォン縦画面を優先し、横スクロールなしで長い日本語を折り返します。上部の画像とステータスは320px幅でも2列を保ちます。タイトル、上部、中央ログ、下部入力欄が重ならないよう、短い横画面では上部画像の幅を調整します。中央ログだけが縦スクロールし、3行の入力欄は142pxのコンパクトな固定高です。PCでは最大幅760pxで中央に配置します。

ブラウザテストは320×640、390×844、1280×800、812×375で、指定文字サイズ、配色、イベント画像10種の読み込み、画像とステータスの位置、入力欄の高さ、領域同士の重なり、選択肢の文字切れ、横スクロールを確認します。タップ、マウス、数字キー、ログのスクロール、文字送りのスキップ、Reduced Motion、再スタートも操作します。テストのChromiumはブラウザ自動化による確認です。実機のiPhone SafariやAndroid端末では検証していません。

# 画面と操作

## 表示

黒背景、緑中心の等幅文字、細い枠線を使うターミナル風デザインです。常時表示する項目はタイトル、15マスの進行、区画番号、現在電力、イベント名と説明、観測、行動ボタンです。イベント結果は最新の電力変動を示し、過去ログは折りたたみます。

成功率、安定／劣化の内部状態、乱数シードは画面に表示しません。行動ボタンには行動名と、成功・失敗時に適用される電力差分を表示します。失敗すると0で停止する選択肢には警告を添えます。

## 操作

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 行動を選択 | クリック、または1・2・3キー | ボタンをタップ |
| 過去の結果を確認 | 「イベントログ」を開く | 「イベントログ」をタップ |
| 終了後に再挑戦 | 「新しいランを開始」 | 同じボタンをタップ |

新しいランでは新しい乱数シードを生成し、電力・位置・区画状態・履歴を初期化します。終了後は行動キーとボタンで状態を変更できません。

## レスポンシブ対応

幅320pxを最小対象にし、横スクロールなしで選択肢を表示します。行動ボタンは高さ44px以上でタップ領域を確保します。初期状態では電力と全選択肢が画面内に収まるようにし、ログだけを折りたたみます。狭い画面で長い履歴を開いた場合はログ欄を縦スクロールできます。

ブラウザテストは320×640、390×844、1280×800、812×375で幅超過を検査し、スマートフォン幅ではタップ、PC幅ではクリックと数字キーを操作します。テストのChromiumはブラウザ自動化による確認です。実機のiPhone SafariやAndroid端末では検証していません。

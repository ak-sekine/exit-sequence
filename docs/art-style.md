# 画像制作仕様

ゲーム内のストーリー画像とイベント画像は、ターミナルに表示するSFコメディ漫画の線画として統一します。

## 出力形式と色

- PNG、320×200 px、8:5。ファイル名と画像の分類は既存のIDを維持します。
- 背景は不透明な `#030604`、線は `#4fd66a` です。
- 使用するのは背景色と線色だけです。アンチエイリアスによる両色の中間色は使えます。
- 線画のみとし、緑や灰色の面塗り、グラデーション、ぼかし、発光、写真風の光源表現を加えません。線がない箇所は背景色のままにします。
- 文字やラベルを画像に描き込みません。表示する設備は形と記号で伝えます。

## 主人公ロボット

既存の主人公と同じキャラクターだと分かるよう、次の形を各画像に引き継ぎます。

- 丸く大きな頭と、顔の大部分を占めるディスプレイ。
- 大きな目。驚き、喜び、困惑、疲れなどは目の形・眉・顔の向きで表します。
- 短いアンテナ、丸みのある胴体、短い手足。
- スカベンジャー用の回収バッグ。

色に頼らず輪郭と形で識別できるようにします。ストーリー3枚では基本形を揃え、イベント画像でも同じ頭・顔・アンテナ・バッグを使います。場面に合わせて手足を大きく動かし、ロボットの感情や行動を伝えます。

## 線と構図

- 輪郭は手描き漫画風に、320×200 px上でおよそ2〜3 pxの太さではっきり描きます。目や設備の要点に限り細い線を使います。
- 人物や設備は丸みのある単純な形に整理し、細かな継ぎ目や機械図面のような構造を描き込みません。
- 表情、ポーズ、集中線、動きの線で場面を伝えます。必要な陰影は短いハッチング線を少量だけ使います。
- 主役となるロボットと設備を大きく置きます。背景は床、壁、配管など場面の把握に必要な輪郭だけに抑えます。
- 画像だけで何が起きているか読み取れるよう、設備の特徴的な外形とロボットの反応を優先します。

## スマートフォンでの視認性

- 画像は幅320 pxを上限に表示し、短い横画面では8:5比率のまま縮小します。
- 幅約170 pxで見ても、主人公の輪郭、目の表情、場面の設備が判別できる大きさにします。
- 小さな部品、細い網目、連続する背景線を避け、細部で主役の輪郭を埋めないようにします。

## 新しい画像のレビュー項目

- [ ] PNGで320×200 px、8:5、透過なしになっている。
- [ ] 背景が `#030604`、線が `#4fd66a` で、中間色はアンチエイリアスだけに限られている。
- [ ] 線画だけで、色面・灰色面・グラデーション・発光・ぼかしがない。
- [ ] 文字がなく、設備と状況を形で説明できている。
- [ ] 丸い頭、大きな目、短いアンテナ、丸い胴体と手足、回収バッグで主人公を識別できる。
- [ ] 表情とポーズが読み取れ、主要な設備や出来事が一目で分かる。
- [ ] 背景は簡潔で、線の密集が主役を邪魔していない。
- [ ] 幅約170 pxに縮小した状態でも主役と場面を判別できる。
- [ ] 既存画像の一覧に並べたとき、線の太さ・省略度・キャラクターの形が揃っている。

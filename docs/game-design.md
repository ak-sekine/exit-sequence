# Exit Sequence ゲームデザイン（正本）

## 中心

文章から現在の状況・危険・手掛かりを読み取り、限られた知識・道具・身体状態を考慮して行動を選ぶ短編SFサバイバルゲームブック。文章を読むこと自体をゲームプレイにする。地図を覚える必要はない。

**読む → 音・光・呼吸・記録を解釈する → 行動を選ぶ → 状態・知識・持ち物・脅威が変わる → 次の場面を読む。**

舞台は致命的損傷を受けた月面基地。帰還船で脱出する必要があり、サポートAIが同行し、一体のロボットが脅威となる。主人公の名前・性別・年齢・職業、事故の詳細や大きな陰謀は確定しない。

## SceneとChoice

進行単位はScene。場所の位置関係ではなく、そのとき置かれた状況を表す。id、短いnarrative、条件付き追加文章、choices、終了種別を持つ。Choiceは主人公の判断・意図・行動を文章で示す。方向や移動先名だけのボタンは使わない。

Choiceは条件、効果、結果文章、次Scene、条件別遷移を持つ。知識・道具によって選択肢を追加し、負傷などで選択肢を制限する。通常2～5個。制限後や最後の手順確認では1個の場合もある。選択は確定後に取り消せない。

固定シナリオの選択結果は、選択と現在の状態・知識・道具から決まる。重要な判断を成功率判定に委ねない。本プロトタイプは乱数を使わない。

## 文章は判断材料

音の遠近、三度の金属音、赤い走査光、白い灯りへの反応、青い表示の継続、袖口の漏れから危険と設備の性質を判断する。危険な行動の前に、その危険を観察できることを原則とする。機械的に不可欠な注意はAIが補足する。

文章は児童文学くらいの読みやすさで、状況がすぐ分かることを優先する。主人公は見えるもの、音、振動、光、空気、呼吸、スーツの感覚と取得した知識による認識を描き、恐怖や焦り、安堵を短く添える。少し強がって軽口を言うが、危険の緊張は保つ。AIは事務的で少し皮肉屋の相棒として、センサー・警告・状態・装置情報を明確に伝える。日本語はAI：、英語はAI:。地の文で敵の内部状態や、未取得の記録内容を先に説明しない。詳しい文体方針は[writing-style.md](writing-style.md)に従う。

序盤の二本の黒い擦過痕は、追跡映像を読んだ後にアーム旋回の痕として認識できる。後の類似描写が低い配管を使う判断につながる。知識を単なる鍵フラグにせず、現象の意味と行動方法を変える。

## 状態と道具

身体（正常／負傷）、酸素（十分／少ない／危険）、ロボット警戒（低／中／高）の三つ。状態は文章と行動条件に反映する。毎Scene同じ定型文を反復しない。一覧画面は使わず、Scene本文と条件付き文章から状況を読み取る。

知識と道具は各4種類。知識は新しい行動と再解釈を可能にする。道具は照射、操作、時間短縮、音への誘導、補給などの行動方法を増やす。内部Stateとして保持し、一覧UIは設けず、使える場面のChoiceと文章に反映する。未来の具体的攻略を明かさない。

## 脅威と遭遇

ロボットは座標ではなく追跡者として扱う。騒音や長い再生などで警戒が上がり、静かな撤退や待機・光・デコイで下がる。警戒の高い場面では音が近くで止まり、走査光が扉をなぞる。警戒が高いときに危険な騒音行動をすると遭遇へ進む。

遭遇は戦闘ではない。光への反応を知って道具を使う、デコイを使う、身体と空気を犠牲に棚へ逃げるなどの判断を行う。暗闇でも走査するという事前情報を無視して、その場で消灯すると失敗する。

## 選択の代償

長い記録は多くの知識を与えるが、酸素と安全な距離を失う。短い要約は光の性質だけ分かる。工具回収は時間が掛かるが、後の操作や手順票の読取りを短縮できる。手作業は空気を節約できても腕を傷める。待つと脅威が下がるが酸素を失う。常に最も得な行動を一つにしない。

## UI・範囲・評価

ヘッダーはタイトルと右上メニュー、中央はこれまでの文章ログ、下は現在Sceneの行動。320pxを含め全幅で行動文を読みやすい一列にする。下部ナビゲーションと状態・持ち物・Knowledge・HELPの一覧UIは廃止する。右上メニューは言語のみのdropdownで、物語を置き換えない。メニュー操作と言語変更、読む時間は進行せず、物語Choiceはundoできない。

ja/enは同じScene・条件・効果・Endingを共有する。言語変更は状態を変更しない。固定短編の縦切りで、10～15分程度の読解と判断体験を目標とする。プレイヤーによる読書速度と再考を含む体験時間は今後測定する。

成功基準は、描写を飛ばすと判断材料を失い、読んだことで危険を予測し、知識と道具で別の解決を選べること。LLM・外部API・戦闘・HP・キャラクタービルド・マップ生成・複数敵・セーブ／ロード・クラフト・リアルタイム制限は追加しない。

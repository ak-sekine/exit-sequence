# Exit Sequence — 短編SFダンジョンRPG

探索 → 敵／イベント → 能力と装備で突破 → 戦利品 → 成長 → 次の区画。自分で作ったキャラクターを育てながら月面基地を脱出する感覚を試す。初見10～15分を目標とするが、人間の所要時間は未測定。

舞台は損傷した月面基地。現在確認できる生存者は主人公だけ。他の人の生死、事故原因は未確定。生命維持が不安定なため、AIと地球行きの帰還船を目指す。認識系が異常なロボットは拘束・攻撃する実際の敵。

居住区 → 整備区画 → 帰還船ドック。一本道に各1寄り道。寄り道を飛ばしても脱出できる。探索は回復、装備、断片的な記録を得る選択。装備のための倉庫戦だけ追加の危険を伴う。必須戦闘3回、寄り道込み4回。

BODYは攻撃と防御、TECHは技術干渉、SENSEは観察と物資発見。全能力1から2ポイントをボタンで配分する。LV2・LV3で各1ポイントを追加。HPだけを管理する。レベルアップと装備選択により次の戦闘の選び方が変わる。

敵行動は事前に公開。強攻撃への防御、閉じた装甲への技術、スキャンへの観察／技術、回復動作への攻撃を組み合わせる。全戦闘行動は敵撃破を除き1ターン。技術の連打は遮断される。能力イベントは3方式とも通行可能で、低い能力には小さな代償がある。正しい経路の発見は目的にしない。

AIは状況・敵データ・取得品・成長を説明し、短い皮肉で応じる。押すべきボタンは指示しない。事故記録は2件までで真相を説明し切らない。

評価は次の行動を考える楽しさ、3ビルドの差、装備取得の喜び、成長の影響、寄り道の判断、自分のキャラクターで攻略する感覚、別ビルドで再プレイしたいか。自動CLEARは面白さの証明ではない。

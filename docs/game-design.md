# Exit Sequence ゲーム仕様書

## 本書の位置づけ

ゲームの中心と設計方針の正本。具体的な数値・仮配置・処理順は [prototype-spec.md](prototype-spec.md)、UIは [ui-layout.md](ui-layout.md)、文章は [writing-style.md](writing-style.md) を正本とする。プロトタイプの数値や16区画の配置は完成版として確定しない。

## ゲームの中心

未知の月面基地を探索し、情報と道具で危険なロボットを避け、脱出物資を集めて帰還船で地球へ向かう。基地は隕石衝突で長期運用不能な致命的損傷を受けている。基地全体の恒久復旧は目的にしない。主人公は基地に残る唯一の人間。名前・性別・年齢・職種、AIの名前、基地の正式名は未決定。

```text
未知の基地を探索 → 区画・設備・アイテムの情報を得る
→ カメラ・近距離センサーでロボットを把握
→ 予測・誘導・隔壁操作で安全なルートを作る
→ 脱出物資を回収 → ロボットを避けて帰還船へ → 脱出
```

攻略の中心は遭遇しないこと。ロボット撃破、武器、HP、戦闘は導入しない。ENERGY配分と設備の順番操作を中心とする旧構造は廃止する。

## マップと探索

プロトタイプは4×4・16セル。上下左右の双方向接続で複数ルートと迂回路を設ける。5×5は実装しない。区画内は1地点とし、固定設備と回収物を扱う。完成版の正式区画一覧・規模・内部地点は未決定。

開始時に基地の全配置は知らない。未探索、接続だけ判明、訪問済み、地図によって判明を区別する。現在地とその隣接接続は分かるが、未判明区画名は「?」。歩いて入った区画の名前と接続を蓄積し、一度得た情報は失われない。

基地配置図を回収すると全区画の名称・配置・固定接続が分かる。静的な地図はロボット位置・次行動・現在通路状態・動的隔壁状態・アイテム位置・危険を示さない。施設案内も未知性を壊さず、訪問して発見した設備のみ扱う。

## ロボット

プロトタイプの敵は1体。通常は通行可能な隣接セルと待機からランダムに選ぶ。1ターン最大1セル。主人公の自動追跡、複雑な巡回・追跡AIは導入しない。CLOSEDや完全通行不能な通路は主人公・ロボット双方が通れない。

主人公がロボットのセルに入る場合、移動していく前に遭遇する。ロボットが主人公セルに入る場合も遭遇する。遭遇後は通常行動を封じ、失敗すればGAME OVERとなる最後の救済だけを残す。高確率の隠れる・強行突破・確実な逃走は廃止する。低確率救済を通常攻略として成立させない。

## 情報取得

| 手段 | 分かること | 分からないこと |
| --- | --- | --- |
| 探索・基地配置図 | 静的な区画名と配置・接続 | 現在の敵・隔壁・物資・危険 |
| 無料の近距離感知 | マンハッタン距離2以内の方向、距離1の強い警告 | 離れた敵の位置・次行動 |
| カメラ | 取得時点の正確な敵区画・動的通路状態 | 次行動、未回収物の所在 |
| 行動予測装置 | 次のロボット行動の確定先（待機含む） | 2ターン以上先の行動 |
| 設置型センサー | 設置地点付近の取得時点の正確な敵区画 | 範囲外の敵 |

距離3以上では近距離警告を出さない。距離2で方向、距離1で隣接と方向を強く通知、距離0で遭遇する。警告はENERGYを消費しない。基本方向は北・南・東・西。斜めに相当する距離2の扱いは単純な仮ルールとする。

カメラは4×4でロボットを実用的に探せる範囲を持つ。情報は未確認・最新・古いで区別する。世界行動後に取得した画像は最新、次の世界行動後には古い。記録参照と新規取得を区別し、古い情報を現在の安全と誤認させない。

予測は表示のために再抽選しない。確定した次行動をそのまま実行する。プレイヤーが誘導・通路を変更した場合は、その予測が無効になったことを明示する。

## 誘導

誘導は射程・ENERGY・設置条件・持続時間・消耗で制限し、確率失敗を基本にしない。使用条件を満たせば確実に誘導先に近づく通行可能な隣接セルを選ぶ。瞬間移動は禁止。対象へ到達したら持続中は留まる。経路が閉鎖されて到達できなくなれば待機する。

近距離型は低消費・短時間・近くのみ。遠距離型は離れた対象に使える代わりに高消費。設置型は現地に置き、後から遠隔起動し、場所に残る。自分誘導は主人公の現在セルを対象とし低消費だが、近すぎると直ちに遭遇する。固定警報装置はその設備まで移動するリスクと引き換えに広範囲・低消費とする。

## 隔壁

開閉で主人公の経路とロボットの移動候補を同時に変える。近距離キー、遠隔キー、使い捨てオーバーライド、設置型制御器を区別する。設置型はその通路に残って後から遠隔操作できる。固定制御盤は現地付近を低消費で操作する。

閉鎖は一時的。プロトタイプでは数ターン後に自動復旧する。永久安全地帯を作らず、閉鎖中に行動する判断を作る。操作で予測先が変わることも明示する。

## アイテムと探索の二層

| 分類 | 性質 |
| --- | --- |
| 携帯型 | 持ち運んで条件に合う場所で使用。消耗品と繰り返し利用品を区別 |
| 設置型 | 携帯して現地設置。一度設置したら回収不可、その場所に残り遠隔起動 |
| 固定設備 | 区画から動かせず、そこにいるときのみ利用。強力・低消費でもよい |

探索の目的は脱出物資と攻略用の道具の二層。最短で脱出物資を集めるか、予測・誘導・隔壁制御・補給・設備のために寄り道するかを選ぶ。

帰還条件は物資回収中心。仮の修理部品・発進キー・帰還用電源・食糧を保持し、帰還船で発進する。設備操作のpower/control/repair/food条件、旧Task列挙は残さない。完成版の必要物資、種類数、名称、配置は未決定。食糧は逐次消費リソースではない。

## ENERGYと進行

ENERGYは安全手段をどこまで使えるか制限する補助リソース。移動・カメラ・予測・誘導・隔壁・センサーに使用する。補給物や固定設備によって回復できる。移動の主目的をENERGY最適化にしない。

文章を読む時間は無制限。メニュー・HELP・BACK・ページング・設定・情報記録参照は非進行。新規情報取得、移動、回収、設置・使用は世界行動とし、ENERGY消費が0でもターンが進む。CLOSED等の無効操作は消費・進行なし。通路状態は回避判断に役立つ範囲で単純化する。

## 判断構造と評価

ロボットの現在地と次行動、カメラを使うか近距離情報で進むか、予測・誘導・隔壁を使うか、どのルートを通るか、道具へ寄り道するか脱出物資を優先するか、ENERGYをどこで使うかが主な判断。

ランダム移動でも、情報と道具で危険を下げられることを検証する。全域カメラ、無料警告、確定予測、確実な誘導、双方に効く隔壁を組み合わせる。無条件の安全や攻略成功保証ではないが、運だけで危険セルへ入ることを強制しない。

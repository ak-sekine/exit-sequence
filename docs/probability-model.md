# 観測と成功確率

この文書は内部ルールを定義します。ゲーム画面では正確な成功率を表示しません。選択前に見えるのは行動と成功・失敗時の電力変動です。

## 隠れた区画状態

各区画は開始時に50%ずつの確率で「安定」「劣化」になります。状態は5マスの区画内で固定です。区画ごとに独立し、同じ状態が連続することもあります。

## 観測

各イベントは区画の状態に応じて、次のいずれかの観測を抽選します。文章はイベントごとに異なりますが、尤度は共通です。

| 観測の種類 | 安定時 | 劣化時 |
| --- | ---: | ---: |
| 安定した値・動作 | 0.62 | 0.15 |
| 断続的な警告・異音 | 0.28 | 0.45 |
| 電圧低下・異常ログ | 0.10 | 0.40 |

どの観測も両方の状態で起こり得ます。ひとつの説明だけで状態が確定することはありません。同一区画で得た観測は、固定された状態を条件として各イベントで独立に抽選されます。

## 行動の成功判定

各行動には基準値 `baseChance` と状態補正 `stableModifier` があります。

```text
安定時の成功確率 = clamp(baseChance + stableModifier, 0.08, 0.92)
劣化時の成功確率 = clamp(baseChance - stableModifier, 0.08, 0.92)
```

成功時以外は失敗です。すべてのイベント行動について、両状態で成功率は0%より大きく100%より小さくなります。基準値と補正はイベント定義に保持し、画面表示用の `GameView` から除外します。

## 観測と履歴からの推測

事前確率は各区画50%です。同一区画の観測と、選んだ行動の結果が増えるたび、安定状態での確率をベイズ則で更新できます。イベント `i` の選択肢 `a` の既知条件付き成功率を `p(i,a,s)`、観測を `o`、成功結果を `r` とすると、状態 `s` の尤度は次の積です。

```text
P(s | 履歴) ∝ P(s) × Π P(o | s) × Π (r が成功なら p(i,a,s)、失敗なら 1 - p(i,a,s))
```

現在イベントの観測も結果判明前の証拠として使えます。過去の選択と結果はイベントログに残り、区画番号を見て同じ区画内の記録を追えます。実装上の推定値は `inferStableProbability()` と `estimateSuccessProbability()` で計算できますが、ゲーム画面には数値として出しません。

## 乱数と再現

ゲームロジックのイベント抽選、施設状態、観測、成功判定は `RandomSource` を受け取ります。テストでは固定値やシーケンスを注入でき、`createSeededRandom(seed)` は同じシードと同じ行動列から同じ進行を再現します。開発時は `?seed=12345` のようにURLでシードを指定できます。通常のランでは新しいシードを作り、画面には表示しません。シードを画面表示すると内部状態を推定できるためです。

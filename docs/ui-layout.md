# 3Dダンジョン操作サンプル UI

黒系背景と緑の線・文字、モノスペース、最大幅440pxを使用する。上からヘッダー、3D表示、累積ログ、仮想ゲームパッドを配置する。ヘッダーは左にEXIT SEQUENCE、右に≡。ステージ、グリッド盤面、UNDO、RESTARTは表示しない。

SVGのviewBoxは320×200。幅に合わせ、透視表示のアスペクト比を維持する。短い画面では表示枠の高さを制限し、SVGの標準の等比縮小で表示する。ヘッダーとゲームパッドは縮めず、ログだけをスクロールさせる。ログは時系列で追加し、最新へ自動スクロールする。ページ全体は100dvh（100vhフォールバック）に収める。

最下部の左に↑／←↓→（52×44px、間隔4px）、右にB・A（左がB、右がA、44×44px以上）を置く。四辺のsafe-area-insetとviewport-fit=coverを使用する。320px幅で横スクロールは発生しない。低い画面ではダンジョン・ログの高さを減らし、操作ボタンを優先する。物理的にヘッダー・操作部・Safe Areaの合計高さすら確保できない画面は対象外。

≡は日本語／Englishのdropdown。再タップ、外側タップ、Escapeで閉じる。言語選択後は≡にフォーカスを戻す。初期言語はブラウザ言語。言語変更は位置・向き・ログ件数を変更せず、既存ログを再翻訳する。保存はしない。aria-controls、aria-expanded、aria-pressed、方向ボタンの翻訳されたラベル、ダンジョンの位置・向きラベル、role=logを使用する。

方向ボタンと補助の矢印キーで前進・回転する。A・Bは有効なネイティブボタン。Aは正面の扉を1回の操作で通過し、位置とログを更新する。正面に扉がなければ変更しない。Bは状態もログも変更しない。操作の詳細は[dungeon-sample.md](dungeon-sample.md)を参照。

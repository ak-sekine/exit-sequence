# ゲームブックUI仕様

上にこれまでの文章ログ、下に現在Sceneの行動、その下に非進行UIのナビゲーションを置く。320pxでは長い行動文が自然に折り返す一列、540px以上では二列。固定6枠と方向・ページ送りは使わない。通常2～5行動、条件で減る。ボタン最低44px、文字は切らず折り返す。

画面高100dvh（100vhフォールバック）、四辺Safe Area、最大幅720px。ページ全体は固定、ログのみ縦スクロール。低い画面では行動領域も縦スクロールできる。最新Scene表示時はログ末尾へ追従し、過去の文章を戻って読める。

物語選択確定時に `> 行動文章`、結果、次Sceneを記録する。過去の文章ログをタップしてもChoiceを再実行しない。履歴のStateはコピーとして保存する。言語変更で当時の文章を再翻訳しても、後で得た知識は過去の場面へ適用されない。

状態／持ち物／知った事実／遊び方／設定は独立した参照画面。確認しても進行しない。参照画面は物語ログを一時的に置き換え、物語へ戻ると同じ履歴と現在Choiceを再表示する。BACKは参照画面のみに存在し、物語選択の取消用途ではない。START前と終了後も設定・参照は可能。Ending後はRESTARTで完全な初期Stateから開始する。ゲームのセーブはない。

STATUSは身体・酸素・ロボット警戒の段階だけ。INVENTORYとKNOWLEDGEは取得済みの簡潔な説明。未取得項目や未来攻略は表示しない。SETTINGS内で日本語／Englishを選ぶ。言語だけlocalStorageへ保存する。保存が禁止された環境でもプレイ可能。

新Scene本文を5ms/文字で表示（仮演出値）。入力・過去ログは即時。表示中は全ボタンを無効化し、ログのタップで全文表示する。prefers-reduced-motionでは即時表示、表示中のreduce変更でも完了させる。AI段落はAI：/AI:。ネイティブbutton、明確なフォーカス、role=log、aria-busy、言語と領域ラベルを維持する。

Chromiumテストは320×640の日英で、両分岐・知識・道具・脅威三段階・状態・非進行UI・言語・遭遇・二つのOVER・通常操作のCLEAR・再開始・タイプ表示を確認する。documentと全ボタンの横幅、44px以上のタップ領域、ログ領域の確保を各操作後に検査する。

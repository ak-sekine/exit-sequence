# グリッド脱出ゲーム UI

上部はEXIT SEQUENCEと≡の言語メニュー。次の行にSTAGE n / 3と直近1件の短い結果。中央は8×8の正方形セルと2行の記号凡例、その下に常時見える短い共通ルール。下部に↑／←↓→のタップ方向ボタン、UNDO／RESTART。

@ / R / B / O / G / # / .を文字で区別する。PLAYERは@と明るい背景、BOXはB、ROBOTはR、HOLEはOと点線、GOALはGと枠。色だけで識別させない。物体がGOAL上にある場合は物体の記号を保持し、小さなGも表示する。

320×640を検証対象とする。モノスペース、背景#07100f、緑#4ade80を再利用。最大幅440px。通常の盤面最大幅280px、高さ700px以下では184pxへ縮小する。全ボタンのタップ領域は最低44×44px、方向は52×44px。320pxでは横スクロールを発生させない。レイアウトはmin-height:100dvh、100vhフォールバック、四辺env(safe-area-inset-*)を使用。高さが不足する画面ではページの縦スクロールを許し、操作を切り捨てない。

CLEAR後は方向ボタンを隠し、STAGE CLEARとNEXT STAGEを表示。最終はALL CLEARとPLAY AGAIN。FAIL後も方向ボタンを隠し、UNDO／RESTARTを残す。UNDOで進行中の状態へ戻ると方向ボタンも戻る。成功／失敗にかかわらずRESTARTは現在ステージをやり直す。

ルールは常時表示し、攻略例や「ロボットに押されて出口へ」というヒントは出さない。即時描画でtypewriter・アニメーション待ち・累積ログはない。手数やスコアを表示しない。

≡は日本語／Englishを選ぶ小さなdropdown。aria-controls、aria-expanded、aria-pressedを持ち、再タップ・外側タップ・Escapeで閉じられる。言語選択後は≡へフォーカス。初期言語はブラウザ言語に従い、保存はしない。言語変更はターン・状態・UNDO履歴を変更しない。盤面はrole=imgと記号のaria-label、結果はrole=status、方向ボタンには各言語のaria-label、キーボードフォーカスには明瞭な枠を付ける。

矢印キーは補助操作。ゲーム進行・失敗復帰・次ステージ・再プレイ・言語変更はタップだけで完結する。

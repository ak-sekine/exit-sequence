# 3Dダンジョン操作サンプル UI

黒系背景と緑の線・文字、モノスペース、最大幅440pxを使用する。上からヘッダー、3D表示と固定ステータス欄の横並び、累積ログ、仮想ゲームパッドを配置する。ヘッダーは左にEXIT SEQUENCE、右に≡。ステージ、グリッド盤面、UNDO、RESTARTは表示しない。

表示行は左の3D表示が約2/3、右のステータス欄が約1/3（間隔6px）。320px幅でも横並びを維持し、各列の最小幅を0にして横スクロールや重なりを防ぐ。ステータス欄は3D表示と同じ高さで常時表示し、ログのスクロールに連動しない。黒背景、緑の文字・ワイヤーフレームと枠線を維持する。

SVGのviewBoxは320×200。幅に合わせ、透視表示のアスペクト比を維持する。短い画面では表示枠の高さを制限し、SVGの標準の等比縮小で表示する。ヘッダーとゲームパッドは縮めず、ログだけをスクロールさせる。ログは時系列で追加し、最新へ自動スクロールする。ページ全体は100dvh（100vhフォールバック）に収める。

最下部の左に↑／←↓→（52×44px、間隔4px）、右にB・A（左がB、右がA、44×44px以上）を置く。四辺のsafe-area-insetとviewport-fit=coverを使用する。320px幅で横スクロールは発生しない。低い画面ではまずログ領域を縮小し、必要なら表示行の高さを制限する。操作ボタンのサイズは維持する。物理的にヘッダー・操作部・Safe Areaの合計高さすら確保できない画面は対象外。

≡は日本語／Englishのdropdown。再タップ、外側タップ、Escapeで閉じる。言語選択後は≡にフォーカスを戻す。初期言語はブラウザ言語。言語変更は位置・向き・ログ件数を変更せず、既存ログを再翻訳する。保存はしない。aria-controls、aria-expanded、aria-pressed、方向ボタンの翻訳されたラベル、ダンジョンの位置・向きラベル、role=logを使用する。

方向ボタンと補助の矢印キーで前進・回転する。A・Bはネイティブボタン。Aは正面の扉を1回の操作で通過し、位置とログを更新する。正面に扉がなければ変更しない。Bは3D表示と2Dマップを切り替える。切替では位置・向き・ログ・訪問履歴を変更しない。操作の詳細は[dungeon-sample.md](dungeon-sample.md)を参照。

## 固定ステータス

今回は方角だけを表示する。日本語は項目名「方角」、値「北／東／南／西」。英語は項目名「Direction」、値「N／E／S／W」。既存のplayer.facing（北0・東1・南2・西3）から毎回表示値を取得し、別の状態変数で二重管理しない。初期表示は北。左右・180度回転で即座に更新し、前進・扉通過では向きが変わらない限り維持する。言語変更時は項目名と値を再翻訳する。

ステータスは独立したsection内のdlに項目名dtと値ddを持つ項目を配置する。将来HPなどを追加できる構造とし、今回は他の項目を追加しない。値の変更はaria-liveで通知する。

## 2Dオートマップ

初期表示は3D。Bで同じ表示枠を2Dマップに切り替え、再度Bで戻る。既存の表示枠、ログ、操作部の配置と方角ラベルは維持する。右側の固定ステータス欄も配置・内容を維持する。

src/automap.tsは3D描画から独立する。訪問履歴は既存座標の文字列キー（x,y）のSetで管理し、初期位置だけを登録する。通常移動・Aの扉通過によって座標が変化したときだけ移動先を追加する。回転・移動失敗・切替は追加しない。再訪は重複せず、履歴は表示切替後も保持する。再読み込み時の保存は行わない。

DUNGEON_MAPの訪問済み床のみを正方形で描画する。未訪問の床・壁・扉・輪郭線は描かない。北は上、東は右。320×200のSVG内で1マス32×32、訪問済み範囲が収まる場合はその範囲を中央に表示し、現在位置は背景色と30pxの↑→↓←で区別する。訪問済み範囲が表示窓を超える軸では同じ縮尺の表示窓が現在位置に追従し、範囲外の訪問済みセルを省略する。履歴自体は保持する。

マップ中は方向ボタンとAをdisabledにし、暗く表示する。イベント処理でも移動・回転・Aを拒否し、矢印キーも位置・向き・履歴・ログを変更しない。Bと言語切替は使用可能。表示枠とBのアクセシブルラベルは日英に対応し、Bはaria-pressedでマップ表示状態を伝える。

単体テストで訪問履歴・重複排除・未訪問非表示・正方形・固定方角を検証する。ブラウザテストで初期3D、B往復、通常移動と扉通過、操作拒否、状態とログの保持、言語切替、320pxとPCの表示切替前後のレイアウト一致を検証する。

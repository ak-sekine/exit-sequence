# 文章スタイル

短文、具体的な動作、状況を先に伝える。日本語の主人公は私、自然な主語省略。英語はI/my、simple English。名前・性別・職業・事故背景は補完しない。怖がりながら軽口を言い、勝利や拾った道具に喜ぶ。毎行冗談にはしない。

AI：/AI: は事実と短い皮肉。プレイヤーを罵倒せず、次に押すChoiceを指示しない。敵行動の数値と能力・装備の効果を平易に伝える。初戦ではルール、以降は短い状況反応でログを圧迫しない。

新しい区画では場所と帰還船への方向を示す。戦闘結果には敵HPと自分HPの変化、キャンセル、撃破、取得品を明示。能力イベントはすべて通行でき、代償と報酬を先に提示する。低能力を不正解として書かない。

導入は損傷した月面基地、唯一の確認済み生存者、不安定な生命維持、地球行きの帰還船、異常なロボットの危険とAI同行を伝える。記録は事実の断片だけ。生死と事故原因は終了後も不明。CLEARは脱出の安堵、GAME OVERはHP0で動けなくなる描写。過去ログへ後の知識を混ぜない。日英は同じ情報と結果を持つ。

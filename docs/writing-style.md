# Exit Sequence 文章スタイル（正本）

児童文学くらいの読みやすさを維持する。短文、短い段落、具体的な動作。Sceneの最初に何が見え、何が起きているかを書く。そのあとで感情や解釈を添える。科学を教科書調にしない。「高い圧力の空気が強く押す」程度の平易さを使う。

主人公は日本語で私、英語でI / my。日本語では自然に主語を省く。名前・性別・年齢・職業・事故背景は補完しない。怖がりながら強がり、軽口で気持ちをつなぐ。失敗は悔しく、成功はうれしい。毎行ふざけず、特定作品の台詞を流用しない。

AIは正確で少し皮肉屋。接頭辞はAI：/AI:。情報を先に伝え、短い皮肉を後に添える。プレイヤーへの罵倒はしない。冗談によって手掛かりを曖昧にしない。ja/enで観察事実・原因・対処方向は一致させ、英語もsimple / clearを優先する。

見えない原因を当てさせない。カバーの外からは氷を断定しない。開けると軸に氷が見え、突起が当たって止まる。圧力は点検窓の矢印、電力は一台と二台の比較で示す。主人公の知らない内部状態を地の文に混ぜない。

AIヒント1は事実の確認、2は場所と原因の明言、最終は平易な原因と対処方向。必要なら点検描写を伴う。最終ではほぼ答えまで示してよい。知識は説明を早く理解するショートカットであり必須条件ではない。

Choiceは具体的な行動。「氷を溶かして直す」という完成した答えを初期画面に出さない。原因が見えたあとに「点検ヒーターを軸に当てる」とする。大量の候補で総当たりさせず、一段だけ考える余地を残す。

結果は変わったもの、変わらないもの、因果の確認を伝える。氷が水滴になり、まだレバーは押していない。その後同じ軸が回る。誤操作では氷が残り金属がきしむ。主人公は「力の問題じゃないな」。AIは短い正確な返しをする。ヒントや普通の誤操作で身体・酸素を悪化させない。

CLEARでは遠ざかる基地と安堵を描く。今回OVERは設けない。言語変更で過去ログに未来の理解を混ぜない。各文章ペアをレビューし、情報の過不足、AI接頭辞、知り得る事実、320pxでの読みやすさを確認する。

## 状況描写の導線

新しい場所へ入ったときは、今いる場所・目的地・障害・解決する理由が文章から分かるようにする。場所が変わった最初のSceneに場所名を添え、inspect/cause/resultで繰り返しすぎない。解決後は何が可能になり、どこへ進み、目的地へ近づいたかを描く。

開始時の前提は謎にしない。月面基地、事故後の損傷、生命維持の危険、他の人から応答がないこと、確認できる生存者は主人公だけであること、地球へ戻る帰還船と経路、停止した設備、ロボットの異常と具体的な危険、最初の目的をwakeの短い段落に分散する。窓を見る、呼びかける、足音を聞くという観察と、AIの正確な説明を組み合わせる。導入Choiceを増やして前提情報を探させない。他の人の死亡は断定しない。危険説明を冗談で曖昧にしない。

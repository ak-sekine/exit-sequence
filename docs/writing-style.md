# 文章スタイル

目的とルールを短く具体的に伝える。ストーリー、登場人物の台詞、AIの説明、長いチュートリアルは使用しない。見せる情報は盤面、記号の意味、共通ルール、直近1件の結果だけ。

@ を G へ。@ / R / B は押され、連なればまとめて移動する。O は物体を消し、@ が落ちるとFAIL。@ が動くとRも1回動き、横方向を優先して近づく。ルールは初めから見せ、推測させない。

結果は「連なった物体を押した」「ROBOT が HOLE に落ちた」「STAGE CLEAR」程度。失敗は「FAIL · UNDO で戻れる」で実験を続けられることを伝える。表示は即時、ログを追加し続けない。

特定の配置の解き方、正解手順、ロボットpushでGOALへ入る攻略などは画面に書かない。攻略方法を採点したり一方を正解として扱ったりしない。

ja/enは同じ情報を持つ。共通記号とUNDO / RESTART / NEXT STAGE / ALL CLEAR / PLAY AGAINを維持し、英語も短くする。言語ごとの状態変更や専用ルールを作らない。

# イベント一覧

## 現行版: 15マス

ブラウザで起動する旧版は、以下10イベントを全区画共通の候補として一様抽選します。各行動の固定成功率はゲーム内表示と同じです。成功・失敗の文章は各行動データに個別定義されています。

| ID | タイトル | 主な状況 |
|---|---|---|
| bulkhead | ごきげんななめの隔壁 | 旧作業区画のロック扉 |
| generator | 二度寝中の発電機 | 放置された発電設備 |
| battery | 拾いもののバッテリー | 値打ちのありそうな蓄電池 |
| leak | ぴりぴり水たまり | 漏電した配線と水たまり |
| charger | 気難しい充電装置 | 傷んだ出力調整器 |
| conveyor | 止まらない搬送台 | 昔の荷物用ベルト |
| emergency | 非常電源の切替器 | 予備系統とミュータントの気配 |
| terminal | おしゃべりな制御端末 | 作業員番号を求める古い端末 |
| cargo-rail | 居座る貨物台車 | 通路を塞ぐ荷台 |
| lift | 途中で休む昇降機 | 地上へ近づく保守昇降路 |

各イベントに3行動、合計30行動があります。イベント画像は `public/events/` の同じIDの320×200 PNGマンガ調イラストです。設備や状況が一目で分かるよう、ストーリー画像と同じ黒地・緑色の手描きマンガ調で統一しています。

## 100マス版: 制作台帳

完成イベント200件の一覧はPhase 2で確定する。Phase 1の時点で200件すべての名称・概要は未定であり、以下は枠と連携プロトタイプを区別する台帳である。各区画は通常イベントを含む候補40件を用意し、プレイでは20件を重複なしで使う。

| 区画 | 距離 | 完成枠 | Phase 2の仮配置案（既存10件） | Phase 1検証データ |
|---|---:|---:|---|---|
| 最深部 | 1〜20 | 40 | ごきげんななめの隔壁 (`bulkhead`)、拾いもののバッテリー (`battery`) | 工具箱の奥の鍵、整備ロボット救出 |
| 廃棄物処理区画 | 21〜40 | 40 | ぴりぴり水たまり (`leak`)、止まらない搬送台 (`conveyor`) | 鍵穴のある保守ハッチ、予備電源切替器 |
| 生産・整備区画 | 41〜60 | 40 | 二度寝中の発電機 (`generator`)、非常電源の切替器 (`emergency`) | 銅線ヒューズ回収（後続連携はPhase 2） |
| 管理・保守区画 | 61〜80 | 40 | おしゃべりな制御端末 (`terminal`)、居座る貨物台車 (`cargo-rail`) | 予備電源連携の昇降機 |
| 地上接続区画 | 81〜100 | 40 | 気難しい充電装置 (`charger`)、途中で休む昇降機 (`lift`) | 救出済みNPCのモモ再会 |

既存イベントの配置は移行案で、Phase 2で名称・本文・成功率・効果を100マス用に確認してから確定する。Phase 1の6プロトタイプ (`prototype-*`) とテスト内の `fixture-z*` は完成数に含めない。200件の確定名、本文、IDはPhase 2/3でこの台帳へ追記し、区画ごとに40件の件数をチェックする。

## 新規イベントの文章レビュー

イベントの文章を作成・変更するときは、[物語の「イベントの文章作成ルール」](story.md#イベントの文章作成ルール)を参照してください。新イベント追加時はすべての行動について以下を人がレビューします。文章の意味的な整合性は自動テストだけでは判定できません。

- 成功文と失敗文が行動結果を明確に表している。
- 成功文・失敗文とそれぞれの電力差分が一致している（成功時にも電力消費があり得る）。
- 成功後・失敗後とも、電力が残れば次のイベントへ進むゲーム進行と矛盾しない。
- 失敗文は障害物を完全な進行不能として扱わず、別経路や別の通過方法があり得る余地を保つ。
- 電力0のGAME OVER、世界観、コメディ調と矛盾しない。

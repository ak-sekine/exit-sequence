# イベント一覧

各行動の固定成功率はゲーム内表示と同じです。成功・失敗の文章は各行動データに個別定義されています。

| ID | タイトル | 主な状況 |
|---|---|---|
| bulkhead | ごきげんななめの隔壁 | 旧作業区画のロック扉 |
| generator | 二度寝中の発電機 | 放置された発電設備 |
| battery | 拾いもののバッテリー | 値打ちのありそうな蓄電池 |
| leak | ぴりぴり水たまり | 漏電した配線と水たまり |
| charger | 気難しい充電装置 | 傷んだ出力調整器 |
| conveyor | 止まらない搬送台 | 昔の荷物用ベルト |
| emergency | 非常電源の切替器 | 予備系統とミュータントの気配 |
| terminal | おしゃべりな制御端末 | 作業員番号を求める古い端末 |
| cargo-rail | 居座る貨物台車 | 通路を塞ぐ荷台 |
| lift | 途中で休む昇降機 | 地上へ近づく保守昇降路 |

各イベントに3行動、合計30行動があります。イベント画像は `public/events/` の同じIDのSVGです。

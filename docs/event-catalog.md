# イベント一覧

各イベントで行動を1つ選ぶと、成功または失敗に応じた電力差分を適用します。表示する差分は最大20・最小0で調整後の値です。成功率そのものはイベントの状態補正と区画の隠れた状態で変わります。式は[確率モデル](probability-model.md)を参照してください。

| イベント | 行動 | 成功時 | 失敗時 |
| --- | --- | ---: | ---: |
| 故障した隔壁 | 電子制御を再起動 | -1 | -5 |
|  | 手動で解除 | -3 | -4 |
|  | 強行突破 | +1 | -8 |
| 不安定な発電設備 | 制御系から再起動 | +5 | -4 |
|  | 補助回路を迂回 | +2 | -2 |
|  | 過負荷で引き出す | +9 | -8 |
| 廃棄されたバッテリー | 出力を同期して充電 | +4 | -1 |
|  | 端子へ直接接続 | +8 | -6 |
|  | 少量だけ抜き取る | +2 | -2 |
| 漏電している通路 | 絶縁経路を探す | -1 | -4 |
|  | 一気に飛び越える | +1 | -7 |
|  | 低速で配線を避ける | -3 | -2 |
| 故障した充電装置 | 出力を調整して充電 | +5 | -3 |
|  | 最大出力で接続 | +8 | -7 |
|  | 低出力で充電 | +2 | -1 |
| 自動搬送設備 | 搬送台に乗る | +3 | -5 |
|  | 制御盤を迂回 | -1 | -3 |
|  | 逆方向へ押し進む | +1 | -7 |
| 非常電源 | 系統を切り替える | +6 | -4 |
|  | 少量を取り出す | +3 | -2 |
|  | 制限を外して引き出す | +10 | -8 |
| 老朽化した制御端末 | 端末を再起動 | +4 | -3 |
|  | 短い命令を入力 | +2 | -1 |
|  | 保守ポートから割り込む | +8 | -7 |
| 封鎖された貨物レール | 台車を手動で動かす | -1 | -5 |
|  | ロックを切り離す | +3 | -5 |
|  | 保守通路を探す | -2 | -2 |
| 停止した昇降機 | 保守はしごを登る | -2 | -4 |
|  | 昇降機を再通電 | -4 | -2 |
|  | 外枠を素早く登る | +1 | -8 |

成功差分と失敗差分はイベントごとに異なります。安定状態に敏感な行動と、設備状態の影響が小さい行動を混ぜています。劣化状態が有利になる行動も含めることで、区画状態だけから全選択肢の優劣が単純に固定されないようにしています。

イベント定義、説明文、観測文、基準確率と状態補正は `src/events.ts` を参照してください。イベントは各マスで一様抽選し、同じイベントが複数回出ることもあります。

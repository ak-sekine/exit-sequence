# イベント一覧

各行動の固定成功率はゲーム内表示と同じです。成功・失敗の文章は各行動データに個別定義されています。

| ID | タイトル | 主な状況 |
|---|---|---|
| bulkhead | ごきげんななめの隔壁 | 旧作業区画のロック扉 |
| generator | 二度寝中の発電機 | 放置された発電設備 |
| battery | 拾いもののバッテリー | 値打ちのありそうな蓄電池 |
| leak | ぴりぴり水たまり | 漏電した配線と水たまり |
| charger | 気難しい充電装置 | 傷んだ出力調整器 |
| conveyor | 止まらない搬送台 | 昔の荷物用ベルト |
| emergency | 非常電源の切替器 | 予備系統とミュータントの気配 |
| terminal | おしゃべりな制御端末 | 作業員番号を求める古い端末 |
| cargo-rail | 居座る貨物台車 | 通路を塞ぐ荷台 |
| lift | 途中で休む昇降機 | 地上へ近づく保守昇降路 |

各イベントに3行動、合計30行動があります。イベント画像は `public/events/` の同じIDの320×200 PNGマンガ調線画です。設備と主人公の反応を簡潔な輪郭で描き、ストーリー画像と同じ黒背景・緑線・キャラクターデザインで統一します。色や線のルールは[画像制作仕様](art-style.md)を参照してください。

## 新規イベントの文章レビュー

イベントの文章を作成・変更するときは、[物語の「イベントの文章作成ルール」](story.md#イベントの文章作成ルール)を参照してください。新イベント追加時はすべての行動について以下を人がレビューします。文章の意味的な整合性は自動テストだけでは判定できません。

- 成功文と失敗文が行動結果を明確に表している。
- 成功文・失敗文とそれぞれの電力差分が一致している（成功時にも電力消費があり得る）。
- 成功後・失敗後とも、電力が残れば次のイベントへ進むゲーム進行と矛盾しない。
- 失敗文は障害物を完全な進行不能として扱わず、別経路や別の通過方法があり得る余地を保つ。
- 電力0のGAME OVER、世界観、コメディ調と矛盾しない。

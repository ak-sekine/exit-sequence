# Exit Sequence：SFゲームブック縦切り仕様

本書の物語・名称・状態変化・長さは**プロトタイプ仮仕様**。完成版として確定しない。設計の正本は[game-design.md](game-design.md)、文章は[writing-style.md](writing-style.md)、UIは[ui-layout.md](ui-layout.md)。10～15分程度の読解・判断体験を目標とするが、人によるプレイ時間は未計測。強制待ち時間は設けない。

通常の地の文は2～4文程度、重要Sceneは5～7文程度を目安に、短い段落へ分ける。重要な警告・条件付き知覚は追加する。児童文学くらいの読みやすさで、光景を先に、主人公の恐怖・焦り・安堵や軽口を後に書く。AIは独立段落で情報を明確に伝え、短い皮肉を添える。緊張を壊さず、AIと追加文も含め320pxで読める長さにする。文章は `src/scenario.ts` の日英ペアで管理する。文体の変更で構造・条件・状態遷移は変えない。

## 主要分岐

導入 → 救急ケース任意 → 最初の危険 → **記録ルート**（情報とライト・デコイ）／**整備ルート**（独立電源と工具・デコイ）→ 袖口の判断 → 痕と走査 → 昇降装置 → 気密室 → 船 → 発進。

危険な開扉、および高警戒時の試験箱・床板・警報・気密室の騒音は遭遇へ割り込む。回避後はrefugeからairlockへ合流する。遭遇は乱数ではなく条件で決まる。

## Stateと処理

`GameState`：scene、body、oxygen、threat、knowledge、items、used、status。

| 状態 | 初期／値 | 変化・文章 |
| --- | --- | --- |
| body | normal／injured | 狭い開口、手動修正・レバー・走行で負傷。手で袖口修正、手動レバー、走行回避を制限。左腕の感覚を描く |
| oxygen | 0十分、1少ない、2危険 | 長い作業・待機で+1。3に達する操作でoxygen-over。予備酸素は0へ戻す。一定の呼吸／目立つファン／薄い空気と警告 |
| threat | 0低、1中、2高 | 音・長い再生で+1、危険開扉+2。静かな撤退・光・待機で-1、デコイ-2。0～2に制限。遠い音／繰返し近づく音／扉の外で止まる駆動音 |

usedは一度の待機（relay-wait）と袖口修正（sealed）を記録する。移動座標やターン、RNGは持たない。

1. 現Scene・status・条件からChoiceを検証。無効なら変更なし。
2. 操作前Stateで、順に条件別routeを判定。
3. 基本effectにroute固有effectを重ねる。取得・消費・知識・身体・酸素・脅威を適用。
4. 酸素が2を超えたら他の遷移より優先してoxygen-over。
5. 次Sceneの終了種別からstatusを決定。UIは確定後Stateのコピーと結果文章を履歴へ追加。

## Knowledge（4）

- light-response：強い白色光は走査を中断し、暗闇は無効。端末の要約／全記録、または工具固定帯の試験札を実際に読むと取得。携帯ライトと非常灯を使う行動が出る。
- arm-traces：二本の痕は旋回するアームの跡。全記録で取得。序盤の痕を後の描写で認識し、アームより低い配管の陰を使える。
- independent-power：青い旧整備系統は独立電源。銘板を確認し工具台へ進むと取得。停電中の青い装置を再解釈し、警報なしで動かす。
- launch-order：圧力固定後に点火。全記録／船の手順票で取得。船で票を読む時間を省ける。

試験札の文字は帯を外す前には隠れている。地の文で未読の全文を知らせない。取得済みリストは観測事実だけを記し、後のScene名や推奨ルートを出さない。

## 具体的な代償（仮値）

- ケース両方：酸素+1、警戒+1。ライトのみ：変化なし。
- 扉から端末：警戒+1。点検蓋：変化なし。強制開扉：警戒+2、遭遇。
- 全記録：知識3つ、酸素+1、警戒+1。要約：光のみ。読まず撤退：警戒-1。
- 工具：酸素+1、光の札。デコイ回収：警戒+1。高警戒なら回収音で遭遇。
- 袖口：工具修正は酸素+1、手修正は負傷、押さえるだけは漏れが残る。未修正で走って回避すると酸素+2（修正済みなら+1）。
- 痕／光による回避：警戒-1。待つ：警戒-1と酸素+1。床板：警戒+1、高警戒なら遭遇。
- 装置：独立電源は知識が必要。手力は正常な腕が必要で負傷。工具は酸素+1。警報は警戒+1、高警戒なら遭遇。一度の待機は警戒-1と酸素+1。
- 遭遇：デコイ消費・警戒-2、光・警戒-1、非常灯は工具と知識・酸素+1・警戒-1。走行は正常な腕と酸素が少ないまでで、負傷・酸素悪化。消灯静止はrobot-over。
- 気密室：自動均圧は酸素+1・警戒-1。工具弁は酸素なし・警戒+1、高警戒なら遭遇。非常開放は酸素+1・警戒+1、同条件で遭遇。
- 手順票：工具なしは酸素+1、工具ありは酸素なし。逆順点火はoxygen-over。

## Endingと通常操作でのクリア例

CLEAR：船で正しい順序を知って実行し、酸素が尽きていないこと。必要物資の一括収集は不要。
OVER：遭遇中に暗闇で静止／酸素危険のまま空気を使う／圧力固定前に点火して排気。

通常ルート：ケース → ライトのみ → 端末 → 光の要約 → 手で袖口修正 → 強い照射 → 警報で装置起動 → 自動均圧 → 船の票を読む → 発進。最後は負傷・酸素危険だがCLEAR。
知識ルート：ライト → 全記録 → デコイを残す → 手で袖口修正 → 痕から低い陰 → 警報 → 均圧 → 記録順に発進。
整備・デコイルートなどは `tests/routes.ts` とChromiumテストに通常操作だけの手順を記録する。全Sceneと全Choiceの到達可能性を探索テストで確認する。

## ja/enとUI

Scene・Choice・条件・効果は同一の定義を使い、Textだけ日英で切り替える。UI共通翻訳はi18n.ts。言語変更はStateと確定Choiceを変更しない。履歴は当時のStateから再描画するため、後で得た知識を過去の描写へ逆流させない。

状態・持ち物・Knowledgeは内部Stateに保持し、一覧UIと下部ナビゲーションは設けない。右上メニューは言語設定のみのdropdownで、物語を置き換えず非進行。物語Choiceはundo不可。表示速度5ms、タップ全文表示、reduced-motion、言語のみlocalStorage保存、Safe Area、320px、GitHub Pagesを維持する。

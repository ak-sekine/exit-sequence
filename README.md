# EXIT SEQUENCE

施設の最深部から地上を目指す、電力管理ゲームです。画面を上部の固定ステータス、中央のスクロール可能なログ、下部の固定選択欄に分けています。中央ログは基本10msごとに1書記素ずつ表示され、イベント説明が終わると下部の選択肢を説明・電力差分まで一度に表示します。明るい緑文字と黒背景のコンソールで、行動結果や手掛かりを読み返しながら出口を目指します。行動の成功率は表示されません。

## 起動

```sh
npm ci
npm run dev
```

`?seed=12345` を URL に付けると同じ乱数列で再現できます。通常のランでは新しいシードを使います。画面やログには内部状態や成功率を表示しません。

## ルール

- 一本道は15マス、電力は最大20で開始します。
- 各マスで10種類のイベントから1つが抽選され、行動を選ぶと次へ進みます。
- 電力は成功・失敗時に増減し、20を超えず、0でゲームオーバーになります。
- 15マス目のイベントを解決し、電力が残っていれば脱出成功です。
- 施設は5マスごとに区画が分かれ、各区画の隠れた状態は区画内で維持されます。
- 各行動の成功・失敗時に変わる電力は選択肢に表示します。

## コンソール操作

出力中にコンソール部分をクリックまたはタップすると、その時点で待っているログ文字を最後まで表示します。PCでは `Space` または `Enter` キーでもスキップできます。スキップは表示だけを完了し、行動や乱数判定、電力、位置には影響しません。中央ログの文字表示中は行動を選べません。イベント説明と観測情報が終わると、3つの選択肢が一度に表示され、行動入力が有効になります。

行動は画面下部のコンソール形式の選択肢をタップまたはクリックして実行できます。PCでは従来どおり `1`、`2`、`3` キーも使えます。選択待ち中はログ末尾に `>` と点滅カーソルを表示します。選択した行動は同じ行へ `> 2. 行動名` の形式で文字送りして確定し、その後に結果を出力します。行動履歴はログに残ります。電力と位置は上部ステータスだけに表示し、ログには行動による電力増減を記録します。過去ログを上にスクロールして読んでいる間は自動で末尾に戻りません。「最新ログへ」で最新の出力位置へ戻れます。再スタートすると前のランのログは消去され、新しいシードで始まります。

OSの「視差効果を減らす」設定が有効な場合、文字送りを省略して全文を即時表示します。

## 実装

- `src/events.ts`：10イベント、行動、観測尤度、成功確率パラメータ
- `src/game.ts`：状態遷移、乱数注入、電力、履歴、推定ロジック、画面向け安全な状態投影
- `src/console-output.ts`：文字送りキュー、スキップ、一時停止、Reduced Motion 対応
- `src/main.ts`：追記ログ、ステータス、選択肢、入力制御
- `src/style.css`：黒背景・緑文字のコンソール表示とレスポンシブレイアウト

ゲーム状態の更新と表示アニメーションは分離しています。内部の区画状態、成功確率、乱数は画面向け `GameView` に含めません。

## 検証

```sh
npm test
npm run build
npm run simulate
npm run dev
npm run test:browser
```

ブラウザテストにはChromiumが必要です。既定の実行ファイルは `/usr/bin/chromium` です。別のChromiumを使う場合は `CHROMIUM_PATH` を指定してください。ブラウザテストは320px幅と横画面を含む複数サイズで各領域の実際の位置と重なりを測り、ログの順序とスクロール、出力スキップ、入力制御、タップ、マウス、数字キー、Reduced Motion、ゲーム終了後の再スタートを確認します。iPhone Safariなどの実機検証は実施していません。

GitHub Pages向けのVite設定とデプロイワークフローを維持しています。

# EXIT SEQUENCE

廃墟から部品を回収して暮らすロボットのぼくは、探索中に床が抜け、廃棄施設の最深部へ落下してしまった。電力が切れる前に、危険なミュータントのいる廃墟を抜けて街へ帰る選択式ゲームです。

ゲーム開始時は専用画像付きのプロローグが表示されます。導入文の全文表示後、「次へ進む ▶」を押すか画面をタップ（PCではSpace・Enter）すると、初回イベントが表示されます。15マスを進み、各行動の成功率と電力の増減を見比べて選びます。スロットの00〜99が表示成功率より小さければ成功。行動結果を読んだ後は、成功・失敗・CLEAR・GAME OVERのどの場合も同じ「次へ進む ▶」で次の場面へ進みます。CLEARとGAME OVERでは専用画像付きの結末を表示し、全文の文字送り完了後に再スタート操作が現れます。

プロローグ、10種類のイベント、CLEAR、GAME OVERの挿絵は320×200のPNG形式です。黒背景・緑文字のコンソールUIはそのままに、ログ内の挿絵を黒背景・緑線だけのマンガ調線画にしています。丸い大きな頭、目のある顔のディスプレイ、短いアンテナ、回収バッグを持つ主人公ロボットを統一しています。詳しくは[画像制作仕様](docs/art-style.md)を参照してください。

```sh
npm install
npm test
npm run build
npm run simulate
npm run test:browser
npm run dev
```

URLの `?seed=42` でイベント抽選を再現できます。詳しくは [ゲームルール](docs/game-rules.md)、[物語](docs/story.md)、[イベント一覧](docs/event-catalog.md)、[バランス](docs/balance.md)を参照してください。

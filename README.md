# EXIT SEQUENCE

施設の最深部から地上を目指す、ターミナル風の電力管理ゲームです。全15マスの各イベントで行動を選び、結果と手掛かりを積み重ねながら出口を目指します。行動の成功率は画面に表示されません。イベントの観測と同じ区画の過去ログから、設備の状態と選択のリスクを推測してください。

## 起動

```sh
npm ci
npm run dev
```

`?seed=12345` を URL に付けると同じ乱数列で再現できます。通常のランでは新しいシードを使います。画面や履歴には内部状態や成功率を表示しません。

## ルール

- 一本道は15マス、電力は最大20で開始します。
- 各マスで10種類のイベントから1つが抽選され、行動を選ぶと次へ進みます。
- 電力は成功・失敗時に増減し、20を超えず、0でゲームオーバーになります。
- 15マス目のイベントを解決し、電力が残っていれば脱出成功です。
- 施設は5マスごとに区画が分かれ、各区画の隠れた状態は区画内で維持されます。
- 各行動の成功・失敗時に変わる電力は選択前に確認できます。

PCはクリックまたは `1`、`2`、`3` キー、スマートフォンは行動ボタンをタップして操作します。ログは画面下の「イベントログ」から開けます。

## 実装

- `src/events.ts`：10イベント、行動、観測尤度、成功確率パラメータ
- `src/game.ts`：状態遷移、乱数注入、電力、履歴、推定ロジック、画面向け安全な状態投影
- `src/main.ts`：画面描画、タップ／マウス／キーボード入力
- `src/style.css`：黒背景・緑文字のターミナルUI

画面とゲームルールは分離されています。内部の区画状態、成功確率、乱数は画面向け `GameView` に含めません。

## 検証

```sh
npm test
npm run build
npm run simulate
npm run dev
npm run test:browser
```

ブラウザテストにはChromiumが必要です。既定の実行ファイルは `/usr/bin/chromium` です。別のChromiumを使う場合は `CHROMIUM_PATH` を指定してください。ブラウザ自動テストは320px幅、タップ、マウス、キーボード、ゲーム終了後の操作ロックと再スタートを確認します。iPhone Safariなどの実機検証は実施していません。

GitHub Pages向けのVite設定とデプロイワークフローを維持しています。

# EXIT SEQUENCE

施設の最深部から地上を目指す、電力管理ゲームです。画面上部には位置と電力だけを固定表示し、中央のスクロール可能なログと3行の選択欄を配置しています。本文や操作表示を濃い端末風の緑 `#4fd66a` に統一し、イベント見出しの直後に陰影を加えた設備SVGをログへ挿入します。テキストは基本10msごとに1書記素ずつ表示し、画像はその場で表示します。行動を選ぶと成功率と2桁スロットが現れ、停止数字で成功・失敗を決めます。行動結果や手掛かりを読み返しながら出口を目指します。

## 起動

```sh
npm ci
npm run dev
```

`?seed=12345` を URL に付けるとゲームのイベント・観測列を再現できます。通常のランでは新しいシードを使います。画面には隠れた区画状態や丸める前の内部確率を表示しません。

## ルール

- 一本道は15マス、電力は最大20で開始します。
- 各マスで10種類のイベントから1つが抽選され、行動結果を読み終えてから「次へ進む」を操作します。
- 電力は成功・失敗時に増減し、20を超えず、0でゲームオーバーになります。
- 15マス目のイベントを解決し、電力が残っていれば脱出成功です。
- 施設は5マスごとに区画が分かれ、各区画の隠れた状態は区画内で維持されます。
- 各行動の観測ベースの整数成功率と、成功・失敗時に変わる電力を選択肢の1行へ表示します。
- スロットの停止数字が成功率未満なら成功です。65%なら00〜64が成功、65〜99が失敗です。
- 10種類のイベントに対応する、陰影を加えた黒背景・緑系のローカルSVG画像を、イベント見出し、説明、観測とともにログへ記録します。

## コンソール操作

通常ログの文字送り中にコンソール部分をクリックまたはタップすると、その時点で待っている文字を最後まで表示します。PCでは `Space` または `Enter` キーでもスキップできます。スキップは表示だけを完了し、行動や電力、位置には影響しません。文字表示中の選択入力は無視され、選択肢の表示完了後に有効になります。

行動は画面下部のコンソール形式の選択肢をタップまたはクリックして実行できます。PCでは `1`、`2`、`3` キーも使えます。選択待ち中はログ末尾に `>` と点滅カーソルを表示します。選択後に行動名と整数成功率をログへ出し、`[ROLL] 00`〜`[ROLL] 99` の数字を50msごとに更新します。画面のタップ・クリックまたはPCの `Space`・`Enter` で停止し、表示中の数字を確定します。確定数字が表示成功率未満なら成功です。ログのスクロール操作はスロットを停止しません。判定後は成功・失敗どちらでも結果表示後に「次へ進む ▶」を表示し、画面タップ・クリック、ボタン、`Space`、`Enter`で進みます。文字送り中のタップ等はスキップだけを行います。進行操作までは解決したPOSITIONとイベント画像を維持し、次イベントを表示しません。再スタートすると前のランのログは消去され、新しいシードで始まります。

OSの「視差効果を減らす」設定が有効な場合、通常ログの文字送りを省略し、スロット数字は回転させずにランダムな数値を静止表示します。停止操作は通常どおり必要です。タブが非表示の間は文字送りと数字更新を一時停止します。

## 実装

- `src/events.ts`：10イベント、行動、観測尤度、成功確率パラメータ
- `src/game.ts`：状態遷移、観測ベース成功率の推定と整数化、確定ロール判定、電力、履歴、画面向け状態投影
- `src/console-output.ts`：テキスト・画像の順序付き出力キュー、文字送り、スキップ、一時停止、Reduced Motion 対応
- `src/main.ts`：追記ログ、50msスロット表示、スクリーン入力、固定ステータス、イベント画像、選択肢
- `src/style.css`：黒背景・緑文字のコンソール表示とレスポンシブレイアウト
- `public/events/`：イベントIDごとの共通サイズのローカル設備SVG10点

ゲーム状態の更新と表示アニメーションは分離しています。画面へ渡す成功率は表示と判定で共有する整数だけです。内部区画状態、丸める前の確率、乱数はDOMへ出しません。スロットの乱数はゲームのイベント・観測乱数と分かれているため、回転時間が次イベントを変えることはありません。

## 検証

```sh
npm test
npm run build
npm run simulate
npm run dev
npm run test:browser
```

ブラウザテストにはChromiumが必要です。既定の実行ファイルは `/usr/bin/chromium` です。別のChromiumを使う場合は `CHROMIUM_PATH` を指定してください。ブラウザテストは320px幅と横画面を含む複数サイズで各領域の実際の位置と重なりを測り、ログの順序とスクロール、出力スキップ、入力制御、タップ、マウス、数字キー、Reduced Motion、ゲーム終了後の再スタートを確認します。iPhone Safariなどの実機検証は実施していません。

GitHub Pages向けのVite設定とデプロイワークフローを維持しています。
